## 1. 电源系统(全车供电,先看这里)

| # | 电源轨 | 链路(原理图已证实) | 用电元件 | 注意 |
|---|---|---|---|---|
| P1 | 48V 输入 | 电池 → **XT60 T1/T2(并联,无切换)** → VIN(46~54V) | 全车总入口 | XT60 防反接靠 D3~D6 SS210 |
| P2 | 24V 电机电源 | 48V → **U24/U23(48_to_24 ×2)** → VCCIN_24_A_1/2 | → MOTOR_1 / MOTOR_2 → DR25 J1/J2 引出 → 4×行走电机控制器 | **MOTOR_1 串 SL1**(PA5 可断),MOTOR_2 不串——急停只能断前轴两轮动力,⚠ 后轴仍带电,需评估 |
| P3 | 12V | 48V → U25(48_to_12) → 12V 轨 | T5 排针 1/2 脚(刀继电器模块供电)、HMI 串口屏、MP3、LED_1、SRD2 触点侧 | 外接继电器模块从 T5 取电,建议模块独立供电并共地 |
| P4 | 5V/3.3V | 12V → U26/U27 → 5_A_V/5_B_V(各 1.5A) → 3.3V | 大板逻辑、74HC245、ADS1115、SBUS、MPU | 5_B_V 供继电器线圈驱动 |
| P5 | **RDK X5 供电(新增,⚠)** | **建议:48V → 独立 48→5V/4A DC-DC Buck → USB-C 给 RDK X5**(RDK X5 用 USB-C 5V 供电,峰值约 4A) | RDK X5 + 相机 | ⚠ **不要从 P4 的 5_A_V/5_B_V(1.5A)取电**——RDK 推流+推理时峰值电流会拉垮大板 5V 轨导致复位。Buck 到货后在台架先带载实测压降 |
| P6 | 电池采样 | 电池/刹车电压 → LM358 → AD6(U18) | 固件 bat 字段(当前占位 48.0,见参数台账 Fw-5) | — |

**上电时序(整车):** 电池开关/XT60 → 大板 48V 上电 → 各 DC-DC 轨建立 → U26/U27 5V → MCU 3.3V 复位释放 → main.c `SW_3=1` 闭合总继电器 → `delay_ms(1500)` 等 AD 稳定 → 外设初始化。**RDK 与 PC 独立供电,与大板共地(共地点见 §5)。**

## 5. 控制链路(RDK X5 ←→ 大板 ←→ PC,核心链路)

| 连接 | 大板侧 | RDK X5 侧 | 说明 |
|---|---|---|---|
| 大板 TX → RDK RX | **PC6**(USART6_TX) | 40-pin 排针 UART 收(RDK X5 具体引脚号到货后从官方 pinout 确认,`/dev/ttyAMA?`) | 3.3V TTL 直连,115200 8N1 |
| 大板 RX ← RDK TX | **PC7**(USART6_RX) | 40-pin UART 发 | 同上 |
| 共地 | GND | GND | **必须共地**(建议与大板 5V/3.3V 域就近一点共地,别借大电流回路) |

⚠ **两个冲突/风险点:**
1. **PC6/PC7 兼接 485 收发器 U7**(DI=PC6/RO=PC7,A_4/B_4 → T6 排针)。U7 若贴片在用,其 RO 会持续驱动 PC7 与 RDK TX 打架 → **B6-5 确认 U7 实物,不用则不贴/拆掉,或确认其 /RE 脚默认禁用**。TTL 引出候选:DR25 J2-18(PC6_OUT)/J1-18(PC7_OUT),经 245 缓冲,245 方向需核对(输出方向对 PC7 作 RX 不利),万用表敲定。
2. **485 第 1/2 路经 DR25 出板挂原车设备**(编码器等)——严禁把 RDK 链路接进 A_1/B_1、A_2/B_2。

| 连接 | RDK X5 侧 | PC 侧 | 说明 |
|---|---|---|---|
| 视频流 | CSI 相机(优先,MIPI)或 USB 相机 → GStreamer/RDK 推流,**MPEG-TS over UDP:5000**(ea5106a 已改 TS,OpenCV udp:// 可解码) | pc/main.py `udp://@:5000` 接收 | 相机选型与驱动是 RDK 适配项(E2.2,ZCode 负责);图传相机装 0.9m 机位,IPM 标定台账 Pc-1 |
| 控制流 | UDP 9000 收 NAV/TOOL/ESTOP(heartbeat 兼容),UDP 9100 发 STATUS(0x10,20Hz) | pc/main.py 发/收 | 5GHz 链路,B8 验收:丢包<1%,p95<50ms |
| RDK 联网 | RDK X5 无线模块能力**到货验机确认**(E2.2 四项验机含推流);若 5GHz 不达标 → E4 定向天线/CPE | PC 开 5GHz 热点 | — |

`vehicle/` 代码现状按树莓派写(serial_dev=/dev/ttyAMA0、gstreamer 管道、dtoverlay)——**RDK 适配已登记台账 Hw-6**,到货后改 config.yaml/桥接/推流三处。

## 7. 接线操作顺序与上电前检查单

**顺序:** 先共地 → 后信号 → 最后功率。具体:
- [ ] P5:RDK 独立 48→5V/4A Buck 到位,台架带载实测(不得由大板 5V 轨供电)
- [ ] 共地:大板 GND、RDK GND、TB6600 GND、继电器模块 GND、电池负极 同电位(逐点量 <0.1Ω)
- [ ] B6-5:U7 是否贴片;PC6/PC7 TTL 引出点敲定(DR25 J2-18/J1-18 候选)
- [ ] T5 第 7/9/11 脚 ↔ PD4/5/6 复核(±1 行风险)
- [ ] PB5/PB6/PB7 引出点找到(找不到 → 飞线决策)
- [ ] 限位开关引出点(T4/T10)确认,常闭型
- [ ] NBREAK1/NBREAK2 实车接法拍照记录(B6 ①②)
- [ ] SL1 只断 MOTOR_1 的风险评估:后轴 MOTOR_2 急停覆盖缺口是否需补(断电机控制器控制电或加继电器)
- [ ] RDK UART 引脚映射确认;图传 MPEG-TS over UDP:5000 收发对通
- [ ] 继电器模块×3 光耦型、高有效、独立供电
- [ ] TB6600 细分数登记台账 Fw-1;限位安装方向与 DIR 正负对上
- [ ] 全部完成后:断开电机动力(拔 MOTOR_1/MOTOR_2 或吊起车轮),先跑 §5 链路对拍(`python common/uart_vectors.py --dump` 8 组向量),再带电试车
