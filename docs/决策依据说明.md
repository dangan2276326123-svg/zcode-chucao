# 设计决策依据说明（组会汇报附件）

> 用途：回答"为什么这样设计"。每个决策按固定格式：**结论 / 被否备选 / 理由 / 证据 / 推翻条件**。
> 最后一条"推翻条件"最关键：它说明每个决策都留了退出机制，不是拍脑袋。
> 日期：2026-09-05。对应方案 v0.7、缺口清单、理论材料（式号均可在其中索引）。

---

## 一、任务边界类

### D1 只做行间除草，不做株间
- **备选**：株间单株识别+机械臂拔除（如 Nindamani 方案）。
- **理由**：株间除草的核心难点是"芍药苗 vs 杂草苗"的单株辨别，幼苗期两者形态几乎不可分，是全行业未解难题；而行间除草只需要"行墙边界"，分割目标从"哪棵是草"变成"哪里是行"，问题难度降一个量级。
- **证据**：开题 1.1 与方案 v0.4 §1.1 一致；李俊论文同样只做行间（其"尚未自主行走"恰是我们的空白论据）。
- **推翻条件**：若导师明确要求株间功能，则项目范围变更，需重排全部试验设计。

### D2 机械中耕，不用化学/激光/机械臂
- **理由**：中草药零农残是硬约束，化学直接排除；激光除草单株处理节拍低、成本高，撑不起"3 亩/日"效率目标；机械臂逐株拔除依赖株间识别（见 D1）。
- **证据**：v0.4 §1.1；王硕博士论文同为机械式。
- **推翻条件**：无——零农残是农艺硬约束，不会变。

### D3 种植场景由林下调整为大田（对开题的调整一）
- **背景**：开题（2026-05）面向"林下"场景，强调斑驳光影与树木遮挡。
- **理由**：实际试验田为大田种植，环境约束简化。但开题承诺的"光影鲁棒性"没有丢——秋季采集清单的光照矩阵（晴天顺光/逆光/阴天）就是该承诺的落地形式；分割模型微调仍覆盖多变光照。
- **证据**：开题报告 1.1；采集清单 §2 拍摄矩阵。
- **推翻条件**：若试验田再次变更回林下，需补采林下专属样本并重估投影误差（树冠遮挡影响 IPM 假设）。

## 二、机械类

### D4 刀头：鸭掌铲主选 + 弹齿对比，圆盘等六种排除
- **备选与排除理由**：圆盘割刀（只切茎叶不切根，与"切断根系除草"目标相悖）；旋转锄（击打式伤苗率高，且转速与 0.5km/h 低速工况耦合失配）；立式除草轮（属株间部件，超出 D1 边界）；往复切割器（不除根+匍匐杂草漏割）；激光/火焰（成本与效率，见 D2）；机械臂（见 D1）。
- **选择理由**：鸭掌铲——行间中耕切根、牵引阻力小、中草药田应用成熟，选型有文献支撑；弹齿——仿形好、伤苗低，与鸭掌铲构成"除草率 vs 伤苗率"的真实权衡，为论文提供数据张力。
- **证据**：选型矩阵完整覆盖 8 种部件（v0.7 §9 表）。
- **推翻条件**：台架/田间若发现鸭掌铲在目标深度伤苗率 >1%，以弹齿为主刀重跑对比。

### D5 三刀布局：两侧固定 + 中间刀视觉主动对行
- **理由**：一次通过清 3 条草带是效率底线；两侧刀固定不依赖视觉（外侧行墙畸变大、识别难），只让中间刀主动——把"最难的感知"用在"最需要的位置"，其余用机械刚性兜底。这个布局同时天然生成论文的核心对比试验（主动 vs 固定）。
- **证据**：v0.4 需求基线；开题研究内容(1)。
- **推翻条件**：无。

### D6 限深：被动仿形（限深轮+四连杆+弹簧），不做主动深度控制
- **理由**：被动仿形无传感器、无控制回路、失效模式是机械性的（可预测），满足 2-4cm 深度精度；主动测距调深是激光/雷达路线的复杂度，与 D2 的成本逻辑矛盾。
- **证据**：v0.4 §5.3 台架验收（平地/10° 坡各 10 点，误差 ≤±5mm）。
- **推翻条件**：台架验证若达不到 ±5mm，再考虑增加深度反馈。

## 三、控制与算法类

### D7 PC 集中算力，感知不上车（对开题"云端上位机"的落地）
- **备选**：边缘端推理（RDK X5 BPU，已在网关硬件中预留）。
- **理由**：一期目标是固定算力变量、验证对行方法本身；模型量化迁移（Horizon 工具链+精度回归）是独立工作量，塞进秋季窗口会挤掉田间试验。真实无线链路是研究内容的一部分——时延分段测量、前馈补偿、开/关对比试验都以链路存在为前提，边缘化会让这些失去研究对象。
- **证据**：v0.4 需求基线原文；理论材料 4.x.2；答辩四问之 Q4。
- **推翻条件**：导师要求边缘演示 → 二期迁移，协议/状态机/安全层零改动（接口已解耦）。

### D8 运动学：四轮差速滑移转向，弃用阿克曼 4WS（对开题的调整二）
- **背景**：开题写 4WD-4WS 四轮转向；实车底盘为四轮独立驱动、靠左右轮速差转向。
- **理由**：运动学模型必须与执行机构一致——实车没有转向轮偏转执行器。滑移转向模型更简单（式 4-1/4-2，可解析推导进论文）；四轮独立速度控制横向修正自由度更大。
- **证据**：大车固件 Out_Pwm 四轮独立 PWM（car_control/main.c）；原理图 TIM1 四通道 PWM。
- **推翻条件**：若后续更换为带转向执行器的底盘，恢复阿克曼模型（nav_control.py 中代码保留可切换）。

### D9 导航线拟合：行投票裁剪 LSQ + 门控加权，弃用朴素 LSQ/Hough
- **背景**：开题承诺"霍夫变换与最小二乘择优对比"。
- **理由**：朴素 LSQ 按像素投票，稠密杂草块（像素多）会压过稀疏真墙（像素少）——消融实测误差 25.5px；行投票裁剪拟合（每行一票、行内散布剔除、离群行裁剪）从机理上消除该偏置，同场景误差 0.5px。Hough 变换对断行断苗的直线假设失效，作为对比基线保留（F9，对齐开题承诺）。
- **证据**：tests/test_adaptive_walls.py（确定性算例 + 随机套件 + 真实掩膜无扰动三组）。
- **推翻条件**：田间实测若行投票拟合出现新的失效模式，增加对应检验项。

### D10 双墙中心线加权：只在单墙严重退化时激活
- **理由**：正常情况下两墙拟合都准确，中点即最优——任何额外权重都是噪声（实测引入 2.2px 偏差）；仅当某墙内点率 <0.5（被严重遮挡）才启用 ±0.25 有界偏好。
- **证据**：三轮设计迭代的消融记录（v1 像素支持度→反向劣化；v2 无界权重→过度偏移；v3→v5 门控版通过全部测试）。
- **推翻条件**：无——这是数据驱动的结论，设计本身来自消融。

### D11 时延补偿用开环前馈，不用 Smith 预估器
- **理由**：Smith 预估器需要被控对象精确模型，行间土壤阻力时变（模型不可信）；e_exec = e_meas + ė·τ 的开环前馈不依赖模型精度，不改闭环特征方程（无稳定性风险）。中位数统计抗 Wi-Fi 重尾。
- **证据**：理论材料 4.x.2；实测链路 p50/p95 待 M1 积累。
- **推翻条件**：试验显示前馈残余误差不可接受时，再考虑带模型的自适应方案（写展望）。

### D12 IPM 用地面 4 点单应，不用解析外参投影
- **理由**：解析解 K[R|t] 依赖安装外参精确已知（车载振动下不现实）；单应矩阵把安装误差全部吸收进 H，标定流程简单（摆标记点→点选→求解），田间可随时重做。
- **证据**：calib_ipm.py 合成自测 0.8px 噪声下误差 5.9mm（验收线 20mm）。
- **推翻条件**：无。

## 四、架构与安全类

### D13 三级看门狗分层（MCU 硬件 IWDG → MCU 链路看门狗 → 树莓派桥接看门狗）
- **理由**：故障模式不同，兜底层级不同——MCU 死机由独立硬件 IWDG 复位（复位后默认 MANUAL 安全态）；无线链路断由 MCU 500ms 看门狗急停+提刀；PC 应用假死由桥接层注入急停（且仅在"PC 60 秒内活跃"时生效，纯遥控作业不被误锁）。三层互为冗余，任一失效仍有下级。
- **证据**：外部审查确认三层设计并推动修复 P0（门控曾未接入真实驱动路径，已整改并重新编译验证）。
- **推翻条件**：无。安全设计只会加层不会减层。

### D14 遥控保留为备份操纵手段（SBUS 旁路）
- **理由**：线控方案 A 的核心优点——遥控链路与自动链路物理独立，AUTO 异常时操作员拨回手动即恢复；"自动失效→人工接管"是农业机械公认的安全范式，也是论文分层安全叙事的素材。
- **证据**：SBUS=PA10 独立于 USART6 协议链路（原理图核对）；固件模式切换逻辑。
- **推翻条件**：无。

### D15 刀控默认安全态：无有效指令 500ms 即提刀
- **理由**：MANUAL 态下车轮不受门控（遥控开车），若刀默认落下且无人指令，等于"车在走刀在转"无监督。改为"TOOL 帧 500ms 新鲜度门控"——指令过期自动提刀，失效方向恒为安全。
- **证据**：外部审查 P1 项整改（retrofit.c apply_outputs）。
- **推翻条件**：无。

## 五、试验类

### D16 三组对比试验：方法/机构/工程各一组
- **理由**：每组对应一个创新点——主动 vs 固定验证创新点 1；鸭掌铲 vs 弹齿支撑创新点 2；补偿开 vs 关支撑后备点 3。统一工况（0.5km/h、3cm、20m）保证组间可比。
- **证据**：v0.4 §9；重复数差异（核心组 5 趟、刀具组 3 趟）的取舍已记录（时间窗口约束下的统计功效平衡）。
- **推翻条件**：导师对重复数或分组有明确要求时按导师意见调整。

### D17 采购 CPE 网桥而非 USB 定向网卡
- **理由**：点对点网桥让 PC 与车端都以有线方式接入，把"无线稳定性问题"收敛到一个专业设备上；USB 网卡在 120m+ 田间空旷环境的性能高度依赖 PC 网卡素质，不可控。腾达套装自动配对免配置，部署成本最低。
- **证据**：B8 一票否决验收（120m 丢包 <1%、p95 <50ms）。
- **推翻条件**：CPE 实测不达标时的升级路径为更高功率型号（预算已留）。

### D18 车端网关选 RDK X5 而非树莓派 4B（价格反转后更新）
- **背景**：Pi 4B 涨价至单板 ¥800+；RDK X5 基础套餐 ¥1015 含 64G 卡/散热/电源。
- **理由**：X5 同价位下多出 10TOPS BPU 与视频硬编码；当前只用它的网关能力（推流+桥接），BPU 为二期边缘推理零成本预留。
- **证据**：缺口清单 E2.2 比价记录。
- **推翻条件**：无。

## 六、一句话总纲（答辩收尾用）

"每一个设计决策都以**任务边界→机理→证据→退出机制**四步论证：行间边界来自农艺约束，机械与算法选型来自作用机理对比，参数来自台架与消融数据，且每条都写明了在什么证据下会被推翻——这份决策记录本身就是论文第 2 章的骨架。"
