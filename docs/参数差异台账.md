# 实车参数 vs 固件/PC 参数差异台账

> 用途:用户已确认**真实除草车与固件内参数存在出入**。本表把固件/PC 里所有"拍脑袋或占位"的参数集中登记,实车测量后填入"实车实测值",批准后改代码并在"状态"列记录。
