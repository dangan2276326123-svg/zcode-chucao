## 1. 表：四轮贴标签，逐格填「前 / 后 / 不转」

**轮名按你眼睛看着车身定的写，不要用代码里的名字**——"代码下标 ↔ 物理车轮"正是待证项之一，用代码名填等于把结论当前提用。

「前」= 相对车头朝前滚；「后」= 朝后滚；「不转」= 完全不动。

| 轮（贴标签） | 纵向 + 前进档 | 纵向 + 后退档 | 横向档 | 备注（轮面朝向对不对）   |
|---|----------|----------|-----|---------------|
| 左前 | 前        | 后        | 前   |               |
| 右前 | 前        | 后        | 前   |               |
| 左后 | 前        | 后        | 前   | 没有转向电机，行走方向被动 |
| 右后 | 前        | 后        | 前   |               |

**后退档怎么给**：油门杆只给非负速度，**往回拉不倒车**。后退是遥控器上另一个开关（通道 3，见 `docs/遥控器键位通道映射表_20260923.md`）。拨过去之后再推油门。
