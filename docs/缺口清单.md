## B. 🔴 硬件在场才能做（全部用户侧，顺序执行）

### B1. 烧录固件 ⚪（等你接板子）
- **做什么**：把 `firmware/大车proj/大车/USER/OBJ/` 下新生成的 hex 烧进大板（J-Link/ST-Link 或串口 ISP）。
- **怎么做**：Keil 里 `Flash → Download`，或 STM32CubeProgrammer 烧 `PWM.hex`。
- **验收**：上电后行为与烧录前完全一致（底盘遥控可开、刀继电器不动）——retrofit 只初始化不干预，MANUAL 是默认态。
- **耗时**：10 分钟。**依赖**：无。

### B2. 串口协议对拍 🔴（固件bring-up 第一关）
- **做什么**：USB-TTL 接 STM32 的 USART6（板 PC6=TX→TTL RX，PC7=RX→TTL TX，共地），PC 发 8 组向量验证解析。
- **怎么做**：`python common/uart_vectors.py COM口`（自动循环发）或 `--dump` 手动灌。USB-TTL 若未采购见 E2。
- **验收**：① 6 组有效帧被正确执行（用心跳+导航帧即可观察：发 nav_straight 时若强制 AUTO 才动作，可先只验证"收到不崩+状态帧 20Hz 出现"）；② `bad_crc_must_reject` 和 `truncated_must_reject` 被静默丢弃（无任何异常动作）；③ PC 端能收到 0x10 状态帧（可用 `python -c` + pyserial 抓打印验证 CRC 通过）。
- **耗时**：1-2 小时（含接线）。**依赖**：B1、USB-TTL×2。

### B3. 接线（按 v0.7 §13.2 引脚表）🔴
| 连接 | 引脚 | 注意 |
| --- | --- | --- |
| USART6 → 树莓派 UART | PC6/PC7 ↔ Pi GPIO14/15，**共地**，Pi 侧 3.3V 电平直连（PC6 输出 3.3V，无需转换） | 树莓派 UART 默认给蓝牙，需在 config.txt 分配（见 B7） |
| 刀继电器 ×3 | PD4/PD5/PD6 → 外接继电器模块输入（74HC245 已升 5V，高有效） | 继电器模块建议光耦型，独立供电 |
| 中间刀步进 | PB6=脉冲 PB5=方向 PB7=使能 → 驱动器对应输入 | 共阳/共阴接法按驱动器手册；驱动器细分数记录下来算系数 |
| 限位开关 ×3 | PD15(原点)/PD10(左)/PD11(右)，开关接地，内部上拉，闭合=低 | 常闭型优先（断线即触发） |
| 急停回路 | 确认 PA5/PF10 现有接线（B6 ①②）后决定是否串入 | 保持常闭硬线原则 |
- **验收**：万用表逐点量通断；上电后限位开关状态能从 0x10 帧的 limits 字节读出（触发位翻转）。
- **耗时**：半天。**依赖**：B1；树莓派部分依赖 B7。

### B4. 三个系数标定 🔴（台架）
| 系数 | 位置 | 做法 | 验收 |
| --- | --- | --- | --- |
| `STEPPER_STEPS_PER_MM` | retrofit.c:15，当前 25.0 | 滑轨装好后：发 tool 帧 ±20mm，百分表量实际位移，反算；驱动器细分数改变时重标 | 10 次往返重复定位 ≤0.5mm（v0.4 §5.4） |
| `c_per_pulse`（轮速） | retrofit.c wheel_speed_update，当前 0.0005 | 顶起车轮，手转整 N 圈，对比 PC 收到的速度积分路程；或拖行 10m 实测 | 误差 ≤5% |
| AD5 电流换算 | retrofit.c `adc_current_a()`（当前返回 0 占位） | 万用表串入电机回路对照 AD5 读数线性拟合；把读取代码接到 iic.c 的 ADS1115 U18 通道 | 误差 ≤0.2A |
| SLEW_ACC 斜坡斜率 | retrofit.c:15，当前 0.2 m/s² | 阶跃切 AUTO 观察：斜率过大→仍窜车；过小→响应滞后（横向纠偏超调）。从 0.1/0.2/0.4 三档试，选定后记入论文标定表 | 切换瞬间轮速无可见跳变且纠偏超调 ≤20% |
- **做法细节**：`adc_current_a` 接线参考 `iic.c` 中 U18（I2C2，PB10/PB11）已有的读法，读 AD5 通道原始码 → 电压 → 按 ACS712-05B 灵敏度 185mV/A 换算，减去静态偏置。
- **耗时**：各 1-2 小时。**依赖**：B2（链路）、B3（机械件）。

### B5. 安全动作实测 🔴（整车台架，对应 v0.4 §8.2）
- **做什么**：逐项验证安全清单。怎么做与验收：
  1. **心跳超时**：进入 AUTO（遥控+PC 同时在线）→ 拔 USART6 线 → 车必须 500ms 内停 + 提刀。 stopwatch 实测（手机录像 240fps 数帧）。
  2. **坏帧注入**：发 `bad_crc` 帧 → 无任何动作。
  3. **ESTOP 锁存**：发 estop 帧 → 之后任何 nav/tool 帧无效 → 按物理复位（接 PD 上按键调 `retrofit_clear_estop`，或重上电）才恢复。
  4. **硬件急停**：按板上急停钮 → 驱动断电 ≤50ms（录像数帧）。
  5. **限位触发**：手挡中间刀滑轨限位 → 0x10 帧 limits 位翻转 + 步进停。
- **验收**：全部留视频/照片存 `hardware_ref/log/`（论文安全章节证据）。
- **耗时**：半天。**依赖**：B2、B3、B4。

### B6. 实物确认 5 项 🔴（看一眼就有答案，尽快做）

5. 485 页 U7（PC6/PC7 的 MAX13487）是否不贴/无外设 → 若占用需换链路串口方案（备选 PA9 单向不成立，会改设计）
- **耗时**：1 小时拍照+记录。**依赖**：无，**本周就做**。

### B7. 树莓派上车 🔴
- **做什么**：Pi 4B/5 刷 Bookworm → 开 SSH → `sudo apt install gstreamer1.0-tools gstreamer1.0-plugins-{base,good,bad,ugly} python3-serial python3-yaml` → **config.txt 加 `dtoverlay=uart0` 把 GPIO14/15 给 UART0** → 填 `vehicle/config.yaml`（serial_dev: /dev/ttyAMA0 或 /dev/serial0，pc_ip）→ 跑 `python3 vehicle/stream_pi.py <PC_IP>`，PC 端 `gst-launch-1.0 udpsrc port=5000 ! application/x-rtp ! rtph264depay ! avdec_h264 ! autovideosink` 看图。
- **验收**：PC 屏上出实时 720p 图，端到端时延（拍秒表对比法）<100ms。
- **耗时**：半天（不含到货）。**依赖**：E2 到货。
