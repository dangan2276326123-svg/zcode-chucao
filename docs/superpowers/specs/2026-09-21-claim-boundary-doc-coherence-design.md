## 0. 为什么会做这一轮

核对"实施方案是否要同步今天查出的事实"时，暴露出两件比预想严重的事：

1. **方案的整条感知线建立在"时间域差"这个诊断上**（夏季→秋季，"域差可修复"），
   而作者现场经验给的诊断是**空间不泛化**：同一套权重在原来那块田能提出双墙，
   换一块田不行。诊断不同，药方就不同——按"季节域差"去秋季微调，
   本质是拿第二个小样本拟合第二个小样本。
2. **文档内部对不上了八处**（其中一处是我今天改文档时自己新埋的编号错），
   包括一处我们前天刚撤回的推论
   （"60 cm 车需压行行走"）仍原样印在缺口清单的"已做完"板上，
   以及 README 把 IPM 接线写成 E2③（实为 E2⑤）。

作者的选择是**不加维度、把主张收到证据能站住的地方**。这份文档就是那把尺子。

## 3. 改单 A · 主张边界（核心）

**A1 — v1.0 §2 第 32 行与第 45 行（V1 感知）**：删除按条件的分层，主张限定到场地。

- 主张限定为"**与训练数据同场地条件下**"的行中心线误差与失败率。
- **删去"按光照（顺/逆/阴）与遮挡分层"**，V1 只报全数据集的聚合量：
  误差四量（均值／标准差／95 分位／最大值）、有效双墙占比、失败率、最长连续失效。
  第 45 行章表里"V1 + 失败帧 + 光照/遮挡分层"同步删。
- **四个采集维度（光照 / 时段 / 行况 / 视角）的定位改了**：不再是实验因子，
  只作为**数据集覆盖说明**——第 3 章写"本数据集采集覆盖了这些条件"，到此为止，
  **不跟任何"不同条件下效果对比"的小节**。

> ⚠️ **改的时候只碰"按采集条件分层"这一义**。"分层"在 v1.0 里还有一义完全不能动：
> 第 27 行与第 269 行`感知行线 → 底盘横向偏差 → 刀具横向位置 → 除草与伤苗效果`
> **按验证环节分层**——那是 V1–V4 的骨架，是整篇论文主线。两处撞同一个词，
> 不做区分的批量替换会把主线拆了。改完必须 grep 复查这两行仍完好。

- **一条连带后果要记下**：§2 第 37 行的预注册允许结论里有"仅部分工况有效"这一档，
  它存在的目的就是防"看完结果再定成功标准"。**V1 不按条件报数，这个结论就没有
  默认到达路径**。处理是"不删能力、只改默认交付"：光照标签仍在目录名里、
  失败帧原始清单照旧保留，所以这句话**将来仍可补数说出，不必重采**；
  只是不再是 V1 的默认产出。这个取舍要写明，不能让预注册那条悄悄变成空话。
- 时段随 A1 一并解决：**不分档报数 → 不需要 EXIF 反推、不需要记录表**。
  原方案里那三个候选（加记录表 / EXIF 自动补 / 收窄主张）只剩第三个，前两个取消。

**A2 — v1.0 §2 表下新增"本文不主张"条**：跨场地泛化不在验证范围内。
理由两条：相邻田块共享场地先验（同一台整地机、同一片土、同样行向与背景）；
