## 2. 改单 A · 主张与统计口径

### A1 — 场地限定语（决定 5）

作者定稿口径：**论文里只写"数据集与田间试验在哪片试验田完成"，其余不写。**
这一句把前两版的绕路都省了——它是**地点声明**，不是逐图归属证明；作者本人可核实，
不需要给每张照片贴地块标签。定稿措辞（写进第 2/3/5 章与本数据集描述）：

> 本研究的图像数据集与田间试验均完成于〔试验田名称/位置〕。数据集按连续采集批次
> 划分训练集、验证集与留出测试集；未逐图建立小区身份标签，不评价小区间差异。
> 结论限于该田块与本研究所开展的试验，不外推至其他田块。

⚠️ **一条底线，越过去这句声明就变成假话**：地点层面成立，不等于逐图层面成立。
秋采若确实跨了相邻若干片，**不得**顺势写"训练集与测试集来自同一田块"这种逐图层面的
话——那正是第二版"同场地条件下"被审查方击中的地方。要跨片就在同一句里写实
（"含相邻若干条垄，未逐垄标注"），主张范围不变。

前两版的自我消耗记在这里以免重犯：第一版写"限定为与训练数据同场地条件下"却又说
田块不记录（两句不能同时成立）；第二版改成"同一采样区域（含若干相邻田块，未逐图
建立地块身份标签）"——措辞合规但绕，把一个简单的地点声明写成了一句没人这么说的
免责声明。**地点 + 不外推**才是同行会写的形式。

### A2 — V1 两类量分开（决定 6），并把聚合定义清楚

"不按条件拆分"是**呈现方式**；"全集聚合"必须说是**哪个集**。第一版没定义，
是它被指出的真缺陷。定稿：

| 报什么 | 用哪个数据 | 为什么只能是它 |
|---|---|---|
| 横向误差：均值／标准差／95 分位／最大值 | 精选标注照片（人工独立标目标线） | 只有这里有**独立真值** |
| 失败率、最长连续失效 | 3 段连续视频（清单 §4 已列，≥30 s，明确不进训练集） | 只有这里**保留时间顺序**，且**未预筛**——无墙、遮挡、草密段都在内 |
| `status=dual` 双墙占比 | 两个集分开报，并注明照片集偏高 | 见下 |

四条必须写死的口径（不新增实验，属于评价有效性定义）：

1. **有符号还是绝对误差**：均值与 95 分位必须分别标明；不能用正负相抵的均值报精度。
2. **失败帧进分母**：误差统计只含"有独立真值且有有效预测"的帧；无法定义误差的帧
   记入失败率分母，**不得记 0，也不得悄悄剔除**。
3. **加权方式**：按帧还是按视频/批次等权，选一种写明（视频长度不等会改变聚合权重）。
4. **最长连续失效**只在保留时间顺序的独立视频上算，注明单位是帧还是秒及所用时基；
   **不得用散拍照片按文件名拼接失效时长**。

**分母悖论与它带来的采集侧后果（必须改采集清单）**：清单 §3 要求标注级照片
"画面内必须含两条完整芍药行墙"。在这类预筛样本上算出的失败率，含义只有
"**在两墙可见的精选样本中失败的比例**"。因此该集合**不负责**田间失败率——
这就是 A2 把失败率交给视频的原因。**副作用要如实说**：
照片集合上报告的双墙占比会**系统性偏高**，须与视频集合的占比并列。

**"dual 只代表算法说自己看到墙，不代表墙的位置对"** 这句也照写，
它由 A2 的分工自然消化：正确性由照片集真值负责，视频集只回答"能不能持续用"。

## 4. 改单 D · 门 N 验收：把软件约束与机械约束拆开（第一版混了）

第一版写的"抓线上帧 + 手推该轴不动双验收"混淆两件事：**撤使能后能否被外力推动，
取决于机构、制动与物理锁定，不能证明软件有没有发运动命令**。拆成两条分别验收：

- **软件约束**：在进入／退出空跑、旧命令残留、掉线恢复、急停复位四种场景下，
  **不产生被禁止的运动输出**（证据＝抓线上帧 + 固件输出状态）。
- **机械约束**：按实际采用的锁定方式确认刀梁与滑台状态（证据＝现场核对表 + 照片），
  判定标准（多大力、允许多大位移）**目前无依据**，本批不发明数字：登记进缺口清单 **B6"实物确认 5 项"类**（作者看一眼滑台与刀梁的锁止机构就能定），定为待补项而**非**待我想一个数。
- 双向都不许反推：不得仅凭"手推不动"判软件约束通过，
  也不得仅因"撤使能后可推动"就认定软件禁止运动失败。

**失视觉观测的措辞降级**（第一版夸了，zcode 上一轮连那句一起批了）：
`run_log.csv` 的 `frame_age_s / recv_timeouts / link_drops` 三列是**症状计数**，
只承诺区分"本地读超时／会话结束、无可用新帧、有图但感知不可用"三类现象；
**相机与网络的根因需车端记录佐证，无车端证据时标未知**。

门 N 该项验收要覆盖的四种场景（沿用已批的"不新增第四项"，仍属第一项的观测面）：
持续无帧；有帧但无可用墙；图像恢复；期间人工夺权。
每场分别核对：状态显示、发出的命令、MCU 输出、实际停止过程。阈值沿用经审查的
控制契约，不在本改单里另设数值。

## 5. 改单 C · S0 升回门 N 的可行性判据（决定 7；第一版降错了）

**为什么要升回来**：§7 把"标注、微调"排在 10 月中→11 月底，而门 N 自主沿行排在
10-05→10-15——**秋季试跑用不上微调后的模型**，只能用手上这套夏季权重；
而现有材料对它的评价正是"过分割 fg≈0.55、双墙不可用"（缺口清单 §C1、采集清单 §4 依据行）。
所以"现有权重能不能提线"不是工量参考，是**能不能跑 AUTO 的判据**。
第一版用"泛化不在研究范围"当作免拦的理由，属不相干推理。

定稿：

> S0 顺路收集可行性线索（不新增一趟），作门 N 试跑前的**输入有效性判据**：
> 现有权重提不出墙 → 秋季按既有退路降级为"遥控 + 感知在线记录 + C1 照采"，
> **不动搬运日、不等微调**；提得出来 → 按门 N 跑 AUTO。
> 进入受控试跑前另确认画面、标定与输入有效性，并验证失视觉时的实际停车行为。

**排期自洽性**：这么定之后，"试跑依赖微调"的暗含矛盾消失——因为试跑明确不依赖它。
§7 与 §8 相应两行同批改。**不得**一面在 §8 写"微调后可用"，一面把微调排在试跑之后。

S0 的产出仍**不含**按条件的分组结论（与决定 甲/2/3 一致）。
