# 纯视觉芍药行间除草机器人 项目计划书（草案）

> 状态：草案，等待用户确认
> 日期：2026-08-14
> 版本：v0.1

## 1. 项目概述与目标

研制一台面向芍药栽培的纯视觉行间除草机器人样机：

- 底盘跨 4 行芍药带作业，一次通过同时清除 3 条草带（3 个行间通道）；
- 全程不依赖 GNSS/RTK，导航与控制完全基于车载单目相机；
- 采用机械中耕除草，不使用化学药剂，满足中草药零农残要求；
- MVP 目标：0.5 km/h 稳定作业、单日有效作业面积 3 亩、药苗损伤率 ≤1%；
- 前期为科研样机与田间验证，后期再考虑商用化。

### 3.2 调研结论

- 行间机械除草是目前唯一同时满足“效率、成本、零农残、低损伤”四条约束的成熟路线；激光除草成本与安全门槛高，机械臂逐株除草效率不足，均不适合本项目 MVP。
- 本项目最独特的组合点不在单点算法，而在“三草带并行 + 中间刀具主动对行 + 单相机 + PC 远程计算”的系统集成，这也是论文创新点的来源。
- 已存在代码（DeepLabV3+ 分割、IPM、双墙中心线、Kalman/PD、4WS 阿克曼、STM32 串口协议）应尽量复用，避免引入 ROS2 导致返工。

## 4. 技术选型与原因

### 4.1 除草机构：鸭掌铲式中耕刀 ×3

选型方案：

- 每把刀采用鸭掌铲（sweep）刀片，安装在三段独立刀梁上；
- 外侧两把刀梁：手动丝杠调距，作业中固定；
- 中间刀梁：加装横向直线滑轨 + 丝杠/步进电机，由视觉导航线闭环微调；
- 每段刀梁带独立限深轮与提刀执行器。

原因：

- 鸭掌铲在 2-4 cm 浅耕下切草根、翻土覆盖，结构简单、成本低、牵引阻力小，适合壤土与 0.5 km/h 低速；
- 被动刀具无需额外动力源，降低车端电气复杂度与故障点；
- 三段独立刀梁保证单刀过载或遇障时互不影响，且满足“中间主动、外侧固定”的对比试验需求；
- 中间刀主动对行只要求 ±2-5 cm 微调行程，丝杠+步进电机即可满足，避免昂贵的电动缸或液压系统。

### 4.2 入土深度控制：被动仿形（限深轮 + 弹簧浮动）

方案：

- 每段刀梁采用平行四连杆挂接，限深轮贴地，弹簧提供下压力；
- 深度 2-4 cm 通过丝杠限位手动调节；
- 限深轮设置触地行程开关，作为深度异常检测输入。

原因：

- 被动仿形结构简单、可靠、成本低，随地形起伏保持刀尖与地表距离稳定；
- 5-15° 坡地低频起伏由弹簧浮动吸收，无需实时闭环；
- 主动电控深度在 MVP 中收益低、成本高，留二期。

### 4.3 安全机制（全部入 MVP）

1. 硬件急停：车端急停按钮 + PC 端软急停，切断驱动与刀具动力；
2. 限深轮触地/过载检测：行程开关或微力传感器，异常时报警并提刀；
3. 视觉丢失自动提刀停车：PC 检测到分割置信度低或链路超时，立即发送提刀+停车指令；车端 MCU 心跳看门狗兜底（超过 300-500 ms 无有效心跳自动停车提刀）；
4. 行端自动提刀：检测到行尾/无行墙时自动提刀，人工确认后掉头；
5. 机械过载保护：刀梁装剪切销或弹簧脱开机构，防止撞石损坏底盘。

原因：

- 药苗损伤率 ≤1% 是硬指标，任何单点失效都必须有机械或电气兜底；
- “PC 软保护 + MCU 硬看门狗”双通道符合功能安全的分层思路，且不增加昂贵安全 PLC。

### 4.4 视觉感知：单相机双任务

方案：

- 保留前视单目相机（现有 1920×1080，已标定），安装位置保证视场覆盖 4 行芍药；
- 复用 DeepLabV3+ MobileNetV2 二分类分割（芍药行墙/背景），不增加杂草分类；
- 后处理从“双墙中心线”扩展为“四行墙 + 三草带中心线”：
  - 远场 ROI：生成三草带导航中心线，供底盘导航与中间刀预瞄；
  - 近场 ROI（刀具所在横向位置）：计算中间草带中心相对刀具的横向偏差，作为中间刀微调控制输入；
- 视觉置信度、无行墙状态作为提刀/停车信号。

原因：

- 行间机械除草不需要逐株识别杂草：整条草带都是作业对象，刀具靠行墙边界避让芍药，天然规避“同类绿”识别难题；
- 单相机同时承担导航与刀具对行，省掉第二路相机与标定，符合低成本要求；
- 二分类模型现有 mIoU 约 0.74，训练数据已存在，只改后处理与控制层，改动面最小。

### 4.5 计算架构：车端最小化，PC 集中计算

方案：

- 车端：STM32（已有，负责底盘驱动、刀具执行、安全看门狗）+ 树莓派（H.264 硬件编码回传图像、UDP↔串口桥接）；
- PC 端：运行现有 Python 视觉栈（分割、IPM、三带中心线）、导航控制器、中间刀控制器、GUI；
- 无线链路同时承载：视频流（PC 接收）、控制帧（PC 下发）、遥测/状态（双向）、心跳（双向）。

原因：

- 现有全部算法与训练流程都在 PC/GPU 上，车端只做采集与执行可避免移植和量化开销；
- 树莓派只做硬件编码与网络桥接，不跑推理，成本低且负载轻；
- 算力集中 PC 便于调试、采集数据、写论文实验。

### 4.6 无线链路：5 GHz Wi-Fi 点对点 + H.264/UDP/MQTT

选型：5 GHz Wi-Fi（802.11ac/ax），PC 侧或车端一侧作 AP，距离 50-150 m；视频用 H.264 低延迟 RTP/UDP，遥测与状态用 MQTT/WebSocket，控制用自定义 UDP 帧（CRC + 序号），心跳看门狗。

原因：

- 需要回传 720p/25-30 fps 图像，带宽需求约 2-4 Mbps，5 GHz Wi-Fi 足够且时延 <50 ms；
- 4G/5G 有资费与公网时延，LoRa/电台带宽不足传视频；
- 60 GHz（WiGig）带宽最高但距离短、怕遮挡，不适合田间；
- 一条 Wi-Fi 链路同时传视频与控制，车端只需要树莓派一个无线口，符合“车端最小化”。

### 4.7 控制系统

- 底盘导航：沿用现有 Kalman 横向滤波 + PD + 4WS 阿克曼 + STM32 串口帧协议，将串口帧改为 UDP 帧封装；
- 中间刀对行：以近场草带中心偏差为输入，位置式 P/PID 控制步进电机驱动丝杠滑轨，行程 ±5 cm；
- 模式切换：手动/自动/提刀/急停状态机，由 PC GUI 与硬件急停共同驱动。

## 5. 系统框架与数据流

```text
┌────────────── 田间车端 ──────────────┐        ┌──────────── 电脑端 ────────────┐
│ 相机 → 树莓派(H.264编码)             │ 5GHz   │ 解码 → DeepLabV3+ 分割         │
│ STM32: 底盘驱动/刀具/限深/安全看门狗  │ Wi-Fi  │ IPM → 四行墙 → 三草带中心线    │
│ 中间刀: 步进电机丝杠滑轨             │◄──────►│ Kalman+PD 导航 / 中间刀 PID    │
│ 限深轮: 行程开关/过载保护            │ 视频+  │ GUI: 监控/参数/软急停/模式切换  │
│ 提刀执行器 ×3 + 硬件急停             │ 控制+  │ 数据记录（论文实验）           │
└─────────────────────────────────────┘ 遥测+  └────────────────────────────────┘
                                       心跳
```

数据流（50-100 ms 闭环）：

1. 相机 → 树莓派 H.264 编码 → Wi-Fi → PC 解码；
2. PC 推理分割 → IPM → 四行墙/三草带中心线 → 近场刀具偏差；
3. PC 计算底盘转向与中间刀偏移 → UDP 控制帧 → 树莓派 → STM32；
4. STM32 执行并回报状态/传感器 → 树莓派 → PC；
5. 任一环节超时或置信度低 → 提刀 + 停车。

时延预算：采集 5-10 ms + 编码 5-15 ms + Wi-Fi 5-20 ms + 解码/推理 20-40 ms + 控制 5 ms ≈ 50-90 ms，对应 0.5 km/h 下 0.7-1.3 cm 位移，满足行间导航与 ±2 cm 对行要求。

## 6. MVP 范围

### 6.1 包含

- 三刀机械中耕机构（鸭掌铲 + 独立刀梁 + 限深轮 + 弹簧浮动）；
- 中间刀主动对行（丝杠滑轨 + 步进电机 + 视觉闭环）；
- 单相机四行墙/三草带感知；
- 现有底盘导航闭环接入；
- 车-电脑 5 GHz Wi-Fi 图传与控制链路；
- 全套安全机制（硬件急停、触地/过载、视觉丢失提刀、行端提刀）；
- PC 监控 GUI 与数据记录；
- 田间验证：除草率、药苗损伤率、横向偏差、效率、中间刀 vs 外侧固定刀对比。

### 6.2 不包含（二期）

- 株间除草；
- 自主头地转弯与全场路径规划；
- 杂草识别与选择性除草；
- 主动电控深度/力控；
- GNSS/RTK 融合；
- 多田块/多作物泛化与商用化。

## 8. 论文创新点（候选）

创新点 1：面向“四行三带”种植模式的多草带并行机械除草与中间刀具视觉主动对行方法

- 单相机语义分割提取四行芍药墙，同时生成三条草带中心线；
- 外侧两刀被动/固定作业，中间刀依据近场导航线实时横向微调，形成“三刀并行、一主动两被动”的作业模式；
- 与固定刀进行田间对比，量化主动对行对药苗损伤率与除草均匀性的改善。

创新点 2：车-电脑无线分布式低成本视觉架构与多级安全联锁

- 车端仅保留 MCU + 树莓派（H.264 编码回传 + 串口网桥），算力集中在 PC；
- 视频/控制/遥测/心跳共用一条 5 GHz 链路；
- 形成“PC 软保护（置信度/链路超时）+ MCU 硬件看门狗 + 机械限深/过载保护”三级安全联锁，保障药苗损伤率 ≤1%。

## 9. 风险与对策

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| 无线图传时延波动导致控制不稳 | 导航/对行超调 | 视频降到 720p/25fps，控制帧与心跳独立小包高频发送；必要时 5 GHz 定向天线 |
| 行墙分割在强光/阴影下失效 | 停车频繁 | 复用现有训练集 + 补充恶劣光照样本；经典 OpenCV 行线检测兜底 |
| 三刀同时过载/卡滞 | 机构损坏 | 独立剪切销/弹簧脱开 + 限深轮触地检测 + 提刀 |
| 中间刀微调响应不足 | 对行偏差大 | 提前预瞄（远场中心线 + 运动学前馈），行程 ±5 cm 留裕量 |
| 试验周期不足 | 论文数据不完整 | 先台架验证中间刀控制，田间只做三组重复对比 |

## 10. 验收指标（MVP）

- 行间除草率 ≥80%（前后杂草覆盖率对比）；
- 药苗损伤率 ≤1%；
- 底盘横向偏差 ≤±5 cm（远场），中间刀对行偏差 ≤±2 cm（近场）；
- 作业速度 ≥0.5 km/h，单日 ≥3 亩；
- 视觉丢失/链路超时自动提刀停车 ≤1 s；
- 完整记录中间刀主动 vs 固定刀对比数据。
