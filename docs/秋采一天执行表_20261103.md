## 3. 一段视频 = 一种条件 = 一个批次（**11-03 第二次改：主路换成录段 + 抽帧**）

> 作者原话"能走抽帧的走抽帧，剩下的拍照"。上一版这张表按类别排 7 个批次、要求边走边按空格切档；再上一版说过"类别在同一走动段里用键切、不换批次号"——那两句都不删，因为抽帧把取舍换了个位置：**现在一段只拍一种条件**，类别不再是按键切出来的，而是"这一段是什么"。段数因此回到 5~7 段，但每段的成本是**一次 `v` + 一次重启**，不是一百次按键。

| 批次 | 这一段拍什么（一种条件） | 录制 | 回来抽帧用的标签 | 估计张数 | 实拍/抽帧（填） |
|---|---|---|---|---|---|
| t01 | 顺光 + 中度杂草 + 正对（主工况） | `v` 录 150 s | `sun_front_front_mid` | ≈150 | |
| t02 | 逆光 + 中度 + 正对 | 150 s | `sun_back_front_mid` | ≈150 | |
| t03 | 阴天 + 中度（**天不阴就不录**） | 120 s | `overcast_front_mid` | ≈120 | |
| t04 | 行间干净（裸土 ≥70%） | 90 s | `sun_front_front_clean` | ≈90 | |
| t05 | 行间茂密（裸土 ≤30%） | 90 s | `sun_front_front_dense` | ≈90 | |
| t06/t07 | 左偏 / 右偏 15° 各一段 | 各 60 s | `..._offsetL_mid` / `..._offsetR_mid` | 各 ≈60 | |
| t08 | **拍照段**：四类干扰特写各 5 张 + C3 的 IPM 素材 | 空格，不录 | 按实际条件逐张切 | 40 上下 | |

张数是估的：150 s @ 25 fps ÷ 每米 25 帧 ≈ 150 张（走速 1 m/s）。**清单第 2 节那些 ≥60/≥30/≥15 是下限，抽出来多于它就是好事**，标注仍按 清单第 5 节的比例抽 150 张。

**为什么一段=一批次是干净的**：`tools/split_dataset.py` 按文件名首段（批次号）分组切 train/val/test，而一段视频就是一次连续拍摄——抽出来的帧沿用同一个批次号，近重复帧不可能一半进训练一半进测试。反过来，**两块地、两次走动绝不共用一个号**；中间停下来做了别的事（比如回去量 M8），回来再录就换新号。批次号全局递增，别在别的目录又从 `t01` 重新开始（采集清单第 6 节那条数据有效性警告）。

**抽帧三条规矩**（详见采集清单 §0B 与台账 Pc-19）：① 间隔按位移算并向上取整（`--stride-m 1.0`，清单第 3 节那个 ≥0.5 m 是下限，四舍五入会悄悄低于它）；② 一段只一种条件（`--category` 一次给整段）；③ **筛帧只筛训练集**——用现有权重挑 `status=dual` 是 S0 那一步，可以做在训练集上，但验证/测试集不许用模型筛，那等于让判卷老师进考场。
