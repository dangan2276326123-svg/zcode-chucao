# 画线漏沙采集（2026-11-20）

目的：地里没作物，用**地面画线**模拟芍药带、车带**漏沙**留实际走线，采工程调试用的视频。
**这一路的读数不进论文**（作者 11-13 裁定：调车专用；论文实验只有春测真作物那一处）。
本次规模：20 分钟以内，先小跑，素材不行再补。

## 0. 两条路，先选一条

| 路 | 谁录 | 能看见画面 | 前提 |
|---|---|---|---|
| **A 边看边录（主路）** | 笔记本拉 X5 的流、边看边录 | 能 | 网桥通 |
| B 车上本地录（兜底） | X5 自己录 | 不能 | 网线/网桥断时用 |

两条**不能同时开**：相机同一时刻只给一路（同一块 `/dev/video0`，两路同占没在这块板上实测过）。

## 1. 路 A：边看边录（网桥）

**接线/IP**：笔记本与 X5 都在网桥上，X5 仍 `192.168.127.10`，笔记本 `192.168.127.100`；
先 `ping -n 100 192.168.127.10`，丢包要 <1%。⚠️ 田间距离的正式拉距（B8）到今天仍是空的，
这一趟的 `link_drops` / `recv_timeouts` 就是现场读数。

**X5 上（一条命令，后台起流，断开 SSH 也不停）**：

```sh
cd ~/qoder
pkill -f record_local.py          # 车上一旦有本地录，先停（相机独占）
pkill -f stream_pi.py
nohup python3 -u vehicle/stream_pi.py --width 1920 --height 1080 > stream_pi.out 2>&1 &
tail -n 3 stream_pi.out           # 看到 run: gst-launch-1.0 ... 就行
```

**笔记本上**：

```sh
python -B tools/watch_record.py --batch t20 --session-min 20
```

窗口里能看到画面，上面两行字：`REC/WAIT`、段号、本段/剩余时间、链路 age、丢线次数、已写帧数。
到 20 分钟自己停；`q` 或 Ctrl-C 收尾。**看画面**与**录进文件**是同一路帧，但状态字只画在
窗口上，文件里是干净帧。

**断链怎么办**：超过 1.5 秒没有新帧，当前段自动收尾、恢复后另起一段，日志 `note` 记
`link-gap`——缺口是明的，不会把一段视频的时间轴悄悄压短。连续断很多次 ⇒ 网桥在这段距离
不够用，换路 B。

## 2. 路 B：车上本地录（无网桥/要保底时）

```sh
cd ~/qoder
pkill -f stream_pi.py             # 相机让给本地录
sh vehicle/collect_demo.sh t20 20
```

先检查、再 `nohup` 后台录、到点自停；提前停 `kill -INT <PID>`（别用 -9）。这段**没有画面**，
回来才看。

## 3. 采集时的手上规矩

- 开始后不要碰电脑（路 A 的窗口可以看；路 B 没有窗口）。
- 画线要够长、带弯（S 形、地头转弯），别只跑一条短直线——偏差样本太少。
- 一次只走一种条件；换条件换批次号（t21、t22…），别在同一天同一个批次里混。
- 路 A 的日期用笔记本的钟（X5 的钟可能差几小时）；路 B 要按真实日期落名就传第 4 个参数
  `sh vehicle/collect_demo.sh t20 20 120 1120`。

## 4. 车回来

**路 A（文件已经在笔记本上）**：`data/paint_data/video/t20_MMDD_vNN.avi`，
日志 `watch_log_t20_MMDD.csv`——看每段的 `written` 与 `stream_frames`（差太多说明
笔记本跟不上）、`link_drops`、`note` 里的 `link-gap`。⚠️ 这是流录的：段内丢帧时，
按帧号估的位移会偏快；估的米数不当实测，缺口段分开算（日志的 `note` 与段时长都在）。

**首跑读数（11-20，公园场地、网桥）**：前 ~35 秒的几段是窗口初始化把消费端拖慢留下的碎片，
直接丢掉；长段 written/stream ≈ 87–90%，所以视频回放比实际快约 10%——**位移用日志的实际
秒数算，别用视频时长**。当场 `link_drops`/`recv_timeouts` 全程 0，网桥这段距离是干净的
（120 m 的正式拉距仍未测）。预览已改成 960×540、隔帧显示，写盘还是原帧，下一次应把这
10% 让回写盘。

**路 B（文件在 X5 上）**：

```sh
scp -r sunrise@192.168.127.10:~/qoder/data/paint_data/video ./paint_video
```

看 `record_log_MMDD.csv` 的每段秒数/字节/实测 MB/s/帧数。

逐段播一遍：画线在画面里（没过曝/没糊）、没有整段黑帧、段与段接得上。先小跑这一趟的
意义就是**素材没问题再补量**。
