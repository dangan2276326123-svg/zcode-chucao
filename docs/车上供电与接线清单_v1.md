# 车上供电与接线清单（qoder 版 v1）

> 日期：2026-09-12
> 作者工作区：`D:\ai work\qoder`（本文件为 qoder 侧权威版本；zcode 侧同名文档为其对应物，二者以本项目记忆 `project-hardware-power` 为事实源）
> 面向：非电气背景，尽量大白话。用途：采购 + 接线直接照做。
> 前置问题：RDK X5 与网桥原本都配 **AC→DC 电源砖**，但**车上没有交流电/插排**。
> 结论：**不用 AC、不用逆变器；直接用车上 48V 直流降压给两个设备各自单开供电。**

---

## 0. 已确认的设备事实（采购前先认这三条）

| 设备 | 供电要求 | 来源 |
| --- | --- | --- |
| **RDK X5（车端大脑）** | **USB-C 供电口，需要 5V/5A（25W）** 的电源——**官方手册明确**："接口 1 作为供电接口，需要使用支持 5V/5A 的电源适配器" | 用户阅官方手册确认（2026-09-12） |
| **Tenda CPE 网桥（一对）** | **9–13V DC 直供**（≈12V/1A）**或 PoE 网线供电**；配一个 injector（DC 口 + PoE 口 + LAN 口） | 设备铭牌/手册 |
| **笔记本网口** | **只传数据，不供电**（RJ45 网口无 PoE）→ PC 端网桥必须自带电 | 通用常识 |

> **重要更正**：本清单早期版本曾写"RDK 接受 12V"——**那是错的，作废**。RDK X5 是 **5V/5A**，**不要给 12V**（会把 5V 供电口打坏）。给 **5V** 才安全。

## 1. 供电方案（一句话）

**车上 48V 电池 → 各加「保险丝 + 防浪涌(TVS) + 磁环」→ 两条独立降压：**
- 一路 **48V → USB-C 5V/5A** → RDK X5；
- 一路 **48V → 12V/≥1.5A** → 车端网桥 DC 圆口。

两条**都单开**（**不挂大板那条 12V/5V 共享轨**）。

**为什么单开、不蹭大板**（大白话）：
- 大板那条 12V 已经养着 HMI 屏、继电器、MP3——它们一开一关会让电压"抖"；
- 它和"动力大板"共用一条命，电机一冲会连累大脑；
- 我们要"急停后还能看到画面"，所以大脑/链路要接在**急停切不断**的那一路电上。

**为什么 PC 端网桥不能用笔记本网口供电**：笔记本网口只走数据、不送电。PC 端那台网桥得自己带电（见 §3）。

## 2. 车上要买（采购单）

| # | 物品 | 关键参数（照抄给卖家） | 用途 |
| --- | --- | --- | --- |
| 1 | **48V → USB-C 5V/5A 宽压模块** ×1 | 输入 **46–54V**；输出 **USB-C、5V、≥5A**（≥25W）。**认准 5A，不是 5V/3A** | 供 **RDK X5** |
| 2 | **USB-C 线（过 5A）** ×1 | 带 **e-marker**、支持 5A 的短线（普通细线带不动 5A，会压降/掉电） | 连 RDK |
| 3 | **48V → 12V 降压模块** ×1 | 输出 **12V、≥1.5A**（网桥 ≈12W） | 供 **车端网桥** DC 口 |
| 4 | **保险丝座 + 保险丝** ×2 | 装在各路 48V 进线处；RDK 路选 **2A**、网桥路选 **1A**（48V 侧总电流 <1A，裕量足） | 过流保护 |
| 5 | **防浪涌 / TVS 模块** ×2 | 跟卖家说"**48V 车用、防电机尖峰**" | 抑制电机噪声尖峰 |
| 6 | **抗干扰磁环** 几个 | 套在 USB-C 线、网线、电源线上各一个 | 抗干扰（EMI） |
| 7 | **12V 圆口公头线** ×1 | 插头**尺寸/正负极先对上网桥 DC 口**，别硬插 | 连网桥 |
| 8 | 短线材 / 端子 / 热缩管 / 共地线 | 若干 | 接线 |
| 9 | *(推荐)* **USB-C PD 电压/电流表** ×1 | 能显示电压/电流的小表（¥30–50） | 上电后实测 X5 实际电流，确认 ≥5A 不欠压 |

> **必须避开的坑**：市面上大量"5V USB-C 车充/降压"只有 **5V/3A（15W）**——**喂不满 RDK 的 25W，满载会掉电重启**。下单只认 **5V/5A**。
> 可选加分：模块若**支持 USB-C PD 协商并广播 5V/5A** 最稳；纯 5V/5A 固定输出也可（X5 手册写的是"支持 5V/5A 的适配器"，不强制 PD）。二者区别只在 USB-C 侧要不要"对话"，都能用。

## 3. PC 端要备

- 一个 **能输出 12V 的便携电源**（12V 输出的 PD 充电宝，或一小块 12V 锂电池）——田头给 **PC 端网桥**供电；电压对上 9–13V。
- 室内/有插座处：直接用网桥**原厂 AC 适配器**。
- 笔记本网口那根网线**只管传数据**。
- 注：PoE 不省电源——injector 自己也要先有电，等于没简化。

## 4. 车上怎么接（网桥不架高）

```
48V 电池(46–54V)
   │
   └─[保险丝+TVS+磁环]─┬─ 48V→USB-C 5V/5A 模块 ──USB-C(5A 线)──→ RDK X5
   （取"急停不断"那一路）│
                        └─ 48V→12V/1.5A 模块 ────12V 圆口线───→ 车端网桥 DC 口

RDK 网口 ──普通短网线──→ 车端网桥 LAN 口
（RDK ↔ PC 走网桥的无线点对点）

全车共地：RDK / 网桥 / 两颗降压模块 / 大板 / 电池负极 —— 接同一个参考点
```

要点：
- **都要 5V，不要 12V**：RDK 只认 5V/5A，接错电压先烧板。
- **只给 RDK 5V/5A**：网桥是 12V，别混。
- **共地**：所有地接同一电位（逐点量通断 <0.1Ω），否则信号对不上、易烧串口。
- **急停那一路取电**：让 RDK+网桥在急停后仍带电，便于看画面/读状态；**MCU 侧安全不依赖 RDK 在线**（由固件 ESTOP 锁存 + 看门狗保证）。

## 5. 现场安全与安装建议

- **加一个总开关**：停车时断开电子设备，避免 48V 电池被持续空耗（X5 待机也有功耗）。
- **48V 是电机母线、噪声大**：磁环 + TVS 是下限；电源线尽量**远离电机动力线**。
- **散热**：X5 满载（BPU 推理）可达 ~25W，5V/5A 模块要留散热空间。
- **线材/接口**：相机 USB 曾两次掉设备（接触不良）——上车**换优质短线、直插 USB3.0 蓝口**，是同一类"接口别省"的问题。

## 7. 与 zcode 版清单的差异说明

- 本版**已把 RDK 供电定为 5V/5A**（手册确认）；zcode 版 §0 的 5V/5A 结论一致，但其 §1 曾"推荐绕开 PD 用 5V 直降"——**5A 属 USB-C 高电流档**，若走 PD 协商更稳，纯 5V/5A 固定输出亦可用（见 §2 注）。
