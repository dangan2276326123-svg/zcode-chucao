## 2. 怎么填（两条路，优先 A）

**A. 用发射机自己的"通道显示 / 伺服显示"页**（约 5 分钟，唯一能一次覆盖 16 路的办法）

1. 遥控器开机进设置，找 Channel Display / Servo Display / 通道监视一类页面。
2. 逐个拨开关、推摇杆，记下**哪一路的数字跟着动**。
3. 每路记三个数：拨到下端的值、中位/松手的值、拨到上端的值。**代码里出现过的判据阈值是 1100 / 1268 / 1300 / 1350 / 1400 / 1450 / 1500 / 1600 / 1700 / 2000**，你记的数要能跨过相关阈值，否则固件根本读不到你的动作。
4. 发射机上根本没有对应开关的通道，直接写"无对应键"，别空着。

**B. 没有通道显示页** → 只能用车上的反应反推，**且只能覆盖 0~6**：

| 想确认 | 动作 | 应看到 |
|---|---|---|
| 油门在哪一路 | 推车上的油门杆 | 车走/屏上速度变 |
| 纵横切换 | 拨一个开关 | **四个轮面转到 90°**（蟹行） |
| 前进/后退 | 拨开关后推油门 | 车换向（注意：往回拉油门不倒车，是设计如此，见台账 Hw-23 ⑧） |
| 停车互锁 | 拨某个开关 | 车立刻不响应油门 |

这条路认不出 7~15（没反应既可能是"空闲"也可能是"你没拨到它"），所以 B 只能当交叉验证，不能替代 A。
