# 车上供电与接线清单（方案 B，2026-09-12 更正版）

> 用途：采购与接线直接照着做。网桥不架高。

## 0. 已确认事实（引用，不再自行推测）

| 事实 | 来源 | 影响 |
| --- | --- | --- |
| **RDK X5 原装适配器 = 5.1V/5A、9V/3A、12V/2.25A、15V/1.8A（多档 USB-C PD）** | 用户实测标签 09-12（台账 Hw-15） | **12V 合法可用、不会烧板**，前提是电源**做 PD 协商**（广播各档由 X5 自选），而不是固定 12V 硬怼 VBUS |
| 车端网桥 9–13V 输入 | 用户确认（Hw-16） | 12V 合规 |
| 48V 侧总电流 ~0.8A（X5 25W + 网桥 12W） | 功耗估算 | 2A 保险丝足够 |

> ⚠️ 唯一要避开的做法：用**固定 12V 输出、不做 PD 握手**的电源硬怼 X5 的 USB-C VBUS——那才会出事。要的是会协商的 PD 源模块。

## 1. 车上要买

| # | 物品 | 关键参数 | 用途 |
| --- | --- | --- | --- |
| 1 | **宽压 USB-C PD 源模块** ×1 | 输入覆盖 **46–54V**；**输出广播 5V/9V/12V/15V（PD 协商）**；功率 ≥30W | 把 48V 变成 X5 能协商的 USB-C 电源（与它原装适配器同机制） |
| 2 | **48V→12V 降压模块** ×1 | 输出 12V、≥1.5A（网桥约 1A，留余量） | 供车端网桥 DC 圆口 |
| 3 | 保险丝座 + 保险丝 ×2 | 48V 进线处，**2A** | 过流保护 |
| 4 | 防浪涌/TVS 模块 ×2 | 跟卖家说"48V 车用、防电机尖峰" | 抑制电机噪声 |
| 5 | 抗干扰磁环 几个 | USB-C 线、网线、电源线各套一个 | EMI |
| 6 | 12V 圆口公头线 ×1 | 插头尺寸/正负极先对上网桥 DC 口，别硬插 | 网桥供电 |
| 7 | 短线材、端子、热缩管、共地线 若干 | — | 接线 |

**买不到 48V 输入的 PD 模块时的退路**：48V→24V 降压 + 一颗 12–24V 输入的 PD 模块（多一个小盒子，功能一样）。

## 2. PC 端要备

- 田头给 PC 端网桥供电：一个 **12V 便携源**（12V PD 充电宝或小块 12V 电池）。
- 室内：直接用网桥原厂 AC 适配器。
- 笔记本网口那根网线**只传数据**，不供电。

## 3. 车上怎么接（网桥不架高）

```
48V ─[保险丝 2A + TVS + 磁环]─┬─ 宽压 USB-C PD 源模块(46–54V 入, 广播 5/9/12/15V)
（急停不断的那一路）           │        └─USB-C 线─→ RDK X5
                              └─ 48→12V/≥1.5A ──12V 圆口线──→ 车端网桥 DC 口

RDK 网口 ──普通短网线──→ 车端网桥 LAN 口

全车共地：RDK / 网桥 / 两颗模块 / 大板 / 电池负极 接同一参考点
```

## 4. 现场的几条安全与工程建议

- **总开关**：停车时断开电子设备，避免 48V 电池被持续消耗（X5 待机也有功耗）。
- **48V 是电机母线，噪声大**：磁环 + TVS 是下限；电源线尽量远离电机动力线；X5 满载（BPU 推理）可达 ~25W，PD 模块要留散热。
- **急停取电点要现场万用表确认**为"常电"（不被急停切断）那一路——这样急停后 X5/网桥仍在线，便于读状态；MCU 侧安全由 ESTOP 锁存 + 门控保证，不依赖 X5 在线。
- **插头正负极先对**（网桥 DC 口），下单前先读设备标签。
