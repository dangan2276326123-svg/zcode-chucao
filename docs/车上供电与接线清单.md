# 车上供电与接线清单（方案 B，2026-09-12 定稿）

> 采购与接线照此执行。网桥不架高。
> 依据：**RDK X5 设备手册（权威）= 5V/5A**；`docs/参数差异台账.md` Hw-15/Hw-16。
> 历史勘误：本文件曾误写"适配器多档 PD、12V 合法"，系由间接信息推断，已作废；以手册 5V/5A 为准。

---

## 0. 已确认事实（引用，不再自行推测）

| 事实 | 来源 | 影响 |
| --- | --- | --- |
| **RDK X5 电源输入 = 5V/5A（25W）** | 设备手册 | **不是 12V**；必须按 5V 供电路线设计 |
| **5V/5A 是 USB-C 的 PD 专属档** | USB-C 规范 | 不协商 PD 时默认上限 **5V/3A（15W）**；25W > 15W，**必须 PD 协商 + e-marker 5A 线**才能可靠拿满。否则满载（BPU 推理）可能欠压/掉电重启 |
| 车端网桥 9–13V | 用户确认 | 12V 合规 |
| 48V 侧总电流 ~0.8A（X5 25W + 网桥 12W） | 功耗估算 | **2A** 保险丝足够 |
| X5 实际是否走 PD 协商 5V/5A | **待实测** | 用 USB-C PD 表串在原装适配器↔X5 之间测一次即可定案（见 §5） |

## 1. 车上要买

| # | 物品 | 关键参数 | 用途 |
| --- | --- | --- | --- |
| 1 | **宽压 USB-C PD 源模块** ×1 | 输入覆盖 **46–54V**；**PD 输出档含 5V/5A**；功率 ≥30W | 把 48V 变成 X5 能协商到的 5V/5A（与它原装适配器同机制） |
| 2 | **e-marker 5A USB-C 线** ×1 | 必须带 e-marker（5A 档的硬性前提） | PD 5V/5A 传输 |
| 3 | **48V→12V 降压模块** ×1 | 输出 12V、≥1.5A | 供车端网桥 DC 圆口 |
| 4 | 保险丝座 + 保险丝 ×2 | 48V 进线处，**2A** | 过流保护 |
| 5 | 防浪涌/TVS 模块 ×2 | 跟卖家说"48V 车用、防电机尖峰" | 抑制电机噪声 |
| 6 | 抗干扰磁环 几个 | USB-C 线、网线、电源线各套一个 | EMI |
| 7 | 12V 圆口公头线 ×1 | 插头尺寸/正负极先对上网桥 DC 口 | 网桥供电 |
| 8 | **USB-C PD 电压/电流表** ×1 | 便宜款即可，能显示协商档（V/A） | **验证 X5 实际协商档**（§5），别省这一步 |
| 9 | 短线材、端子、热缩管、共地线 若干 | — | 接线 |

- **不要买**"固定 12V 输出"的模块，也不要"只到 5V/3A"的模块——前者电压不对，后者功率不够。
- **买不到 48V 输入的 PD 模块时的退路**：48V → 5V/6A 降压模块 + **PD 触发模块（设 5V/5A）**（多一个小盒子，功能等价）。
- 若 §5 实测证明 X5 **不走 PD、直接吃 5V**：则 48V→5V/6A 直降即可，PD 可省（但电源要给足 5–6A）。

## 2. PC 端要备

- 田头给 PC 端网桥供电：一个 **12V 便携源**（12V PD 充电宝或小块 12V 电池）。
- 室内：直接用网桥原厂 AC 适配器。
- 笔记本网口那根网线**只传数据**，不供电。

## 3. 车上怎么接（网桥不架高）

```
48V ─[保险丝 2A + TVS + 磁环]─┬─ 宽压 USB-C PD 源模块(46–54V 入, PD 档含 5V/5A)
（急停不断的那一路）           │        └─e-marker 5A USB-C 线─→ RDK X5
                              └─ 48→12V/≥1.5A ──12V 圆口线──→ 车端网桥 DC 口

RDK 网口 ──普通短网线──→ 车端网桥 LAN 口

全车共地：RDK / 网桥 / 两颗模块 / 大板 / 电池负极 接同一参考点
```

## 4. 现场的几条安全与工程建议

- **总开关**：停车时断开电子设备，避免 48V 电池被持续消耗（X5 待机也有功耗）。
- **48V 是电机母线，噪声大**：磁环 + TVS 是下限；电源线尽量远离电机动力线；X5 满载（BPU 推理）可达 ~25W，PD 模块要留散热。
- **急停取电点要现场万用表确认**为"常电"（不被急停切断）那一路——急停后 X5/网桥仍在线，便于读状态；MCU 侧安全由 ESTOP 锁存 + 门控保证，不依赖 X5 在线。
- **插头正负极先对**（网桥 DC 口），下单前先读设备标签。
