> 采购与接线照此执行。网桥不架高。

> 将电源适配器接入开发板后，绿色电源指示灯亮起，说明供电正常；3.1.0 版本后，橙色状态指示灯闪烁，说明系统运行正常。"

## 0. 已确认事实（手册权威，不再自行推测）

| 事实 | 来源 | 推论 |
| --- | --- | --- |
| **RDK X5 供电口 = USB Type-C 接口 1；输入 = 5V/5A（25W）** | 设备手册原文 | 必须按 **5V** 设计，不是 12V |
| 需"支持 5V/5A 的电源适配器" | 设备手册原文 | 电源要**能输出 5V、承载 ≥5A**；线材/连接器也要能过 5A |
| 绿灯=供电正常，橙灯闪=系统正常 | 设备手册原文 | 上电验收看这两个灯 |
| 供电实现方式（固定 5V 源 vs PD 协商源） | 手册未规定 | **两种都可行**（详见 §1 说明）；本清单给两条路，选其一 |
| 车端网桥 9–13V | 用户确认 | 12V 合规 |
| 48V 侧总电流 ~0.8A（X5 25W + 网桥 12W） | 功耗估算 | **2A** 保险丝足够 |

> **对上一轮说法的更正**：我曾写"5V/5A 必须 PD 协商 + e-marker 线"——这**超出了手册原文**（手册只要求 5V/5A 适配器）。
> 准确表述：**要拿到 5A，线材必须 5A 级**（普通 3A 线过 5A 会发热，这是硬约束）；**电源侧**用"固定 5V/≥5A"或"PD 广播 5V/5A"都可以。
> 唯一要避开的是**只到 5V/3A(15W)** 的源——功率不够，满载（BPU 推理）会欠压/掉电重启。

## 1. 车上要买

| # | 物品 | 关键参数 | 用途 |
| --- | --- | --- | --- |
| 1 | **48V→5V/≥5A 降压模块**（首选）或 **宽压 USB-C PD 源模块（PD 档含 5V/5A）** ×1 | 输入覆盖 **46–54V**；输出 **5V、≥5A（建议 6A 留余量，30W+）** | 供 X5（USB-C 接口 1）。手册要求"5V/5A 适配器"，固定 5V 直降是最直接的对应 |
| 2 | **5A 级 USB-C 线 / 连接** ×1 | 能过 5A（USB-C 走 PD 时需 e-marker；自制线用足够线径） | 5V/5A 传输 |
| 3 | **48V→12V 降压模块** ×1 | 输出 12V、≥1.5A | 供车端网桥 DC 圆口 |
| 4 | 保险丝座 + 保险丝 ×2 | 48V 进线处，**2A** | 过流保护 |
| 5 | 防浪涌/TVS 模块 ×2 | 跟卖家说"48V 车用、防电机尖峰" | 抑制电机噪声 |
| 6 | 抗干扰磁环 几个 | USB-C 线、网线、电源线各套一个 | EMI |
| 7 | 12V 圆口公头线 ×1 | 插头尺寸/正负极先对上网桥 DC 口 | 网桥供电 |
| 8 | ~~USB-C PD 表~~（可选） | 便宜款即可 | 想确认原装适配器实际行为时用；**非必需** |
| 9 | 短线材、端子、热缩管、共地线 若干 | — | 接线 |

**两条路选一（都满足手册"5V/5A 适配器"）**：
- **路 A（首选，简单）**：48V→5V/**6A** 降压模块，输出直接接 X5 的 USB-C 供电（VBUS/GND）。对应手册"固定 5V/5A 适配器"的形态。
- **路 B（等价）**：48V→宽压 USB-C PD 源模块（输入 46–54V，PD 广播含 **5V/5A**）+ e-marker 5A 线。与市面上 5V/5A PD 充电器同类。
- **不要买**：只出 5V/3A(15W) 的；固定 12V 的（电压不对）。

## 2. PC 端要备

- 田头给 PC 端网桥供电：一个 **12V 便携源**（12V PD 充电宝或小块 12V 电池）。
- 室内：直接用网桥原厂 AC 适配器。
- 笔记本网口那根网线**只传数据**，不供电。

## 3. 车上怎么接（网桥不架高）

```
48V ─[保险丝 2A + TVS + 磁环]─┬─ 48→5V/6A(或 PD 源, 5V/5A) ──5A 线──→ RDK X5(USB-C 接口1)
（急停不断的那一路）           └─ 48→12V/≥1.5A ──12V 圆口线──→ 车端网桥 DC 口

RDK 网口 ──普通短网线──→ 车端网桥 LAN 口

全车共地：RDK / 网桥 / 两颗模块 / 大板 / 电池负极 接同一参考点

上电验收：X5 绿灯亮（供电正常）→ 3.1.0 后橙灯闪（系统正常）
```

## 4. 现场的几条安全与工程建议

- **总开关**：停车时断开电子设备，避免 48V 电池被持续消耗（X5 待机也有功耗）。
- **48V 是电机母线，噪声大**：磁环 + TVS 是下限；电源线尽量远离电机动力线；X5 满载（BPU 推理）可达 ~25W，5V 模块要留散热。
- **急停取电点要现场万用表确认**为"常电"（不被急停切断）那一路——急停后 X5/网桥仍在线，便于读状态；MCU 侧安全由 ESTOP 锁存 + 门控保证，不依赖 X5 在线。
- **插头正负极先对**（网桥 DC 口），下单前先读设备标签。
