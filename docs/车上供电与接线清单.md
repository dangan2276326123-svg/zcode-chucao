# 车上供电与接线清单（方案 B，2026-09-12 定稿 v4 · 采购详版）

> 采购与接线照此执行。网桥不架高。
> **权威依据（RDK X5 设备手册原文）**：
> "开发板提供一路 USB Type C 接口(接口 1)，作为供电接口，需要使用支持 5V/5A 的电源适配器为开发板供电。
> 将电源适配器接入开发板后，绿色电源指示灯亮起，说明供电正常；3.1.0 版本后，橙色状态指示灯闪烁，说明系统运行正常。"
> 台账：`docs/参数差异台账.md` Hw-15/Hw-16。历史勘误见文末。

---

## 0. 一句话总览

```
48V 车电池 ─┬─[2A保险丝+TVS+磁环]─→ 48→5V/≥5A 模块 ─→ X5 供电口(USB-C 接口1)
            └─[2A保险丝+TVS+磁环]─→ 48→12V/≥1.5A 模块 ─→ 车端网桥 DC 口
X5 网口 ──普通网线──→ 车端网桥 LAN 口        全车共地
```

**买东西时唯一不能错的三条**：
1. **X5 是 5V，不是 12V**——买 48V→**5V** 模块，且电流标称 **≥5A（建议 6A）**。
2. **别买"只到 5V/3A"的模块**——15W 喂不饱 25W 的 X5，满载会重启。这是最常见的坑。
3. **网桥电压按它自带的适配器标签买**（9–13V 常见 12V），插头尺寸/极性先对上再下单。

## 1. 采购清单（逐项：参数 / 关键词 / 坑）

### 1.1 【最重要】48V → 5V/≥5A 降压模块 ×1（供 X5）

| 项 | 要求 |
| --- | --- |
| 输入范围 | **必须覆盖 46–54V**（48V 电池充满约 54.6V，模块耐压要够，选"宽压 36–72V 输入"最稳） |
| 输出电压 | **固定 5V**（或可调款调到 5.0–5.1V） |
| 输出电流 | **≥5A 持续**，建议 **6A 标称**（留余量、不虚标） |
| 拓扑 | **必须是开关降压（buck / DC-DC）**——❌不能用线性稳压（7805 类）：48V→5V、5A 时有 215W 变热，直接烧 |
| 散热 | 带散热片/铝壳；满载 25W 会有温度，装车留通风 |
| 参考价 | ¥15–40（工业铝壳款更贵但更稳） |
| 搜索词 | `48V转5V 6A 降压模块 宽压` / `DC-DC 36-72V转5V 6A` |
| 坑 | ①虚标电流（标 5A 实际 3A）；②输入耐压只到 40V（X5 满载 + 电池满电会击穿）；③可调款默认输出不是 5V，**收到先调准再接线** |

> **X5 满载约 25W（5V×5A）**，跑 BPU 推理时是峰值。模块和线都要按 5A 冗余设计。

### 1.2 USB-C 供电线 ×1（模块 → X5）

| 项 | 要求 |
| --- | --- |
| 电流能力 | **5A 级**（普通线是 3A，过 5A 会发热/掉压） |
| 接口 | 一头接模块输出（端子/焊点），一头 **USB-C 公头插 X5 的"接口 1"** |
| 参考价 | ¥10–25；买"USB-C 5A 供电线/PD 线"成品改，或买带 CC 电阻的供电转接板 |
| ⚠️ 关键点 | **USB-C 口不是"插上 5V 就能满血"**：合规的 5V/5A 供电，源端需要在 **CC 引脚**上做正确标识（电阻/协商），否则 X5 可能识别为低档电流、甚至不取电。**用固定 5V 降压直连 VBUS 时，务必台架实测 X5 能否正常启动且满载不重启**（见 §5）。若不行，见 §2 的路 B。 |

### 1.3 48V → 12V 降压模块 ×1（供车端网桥）

| 项 | 要求 |
| --- | --- |
| 输入 | 覆盖 46–54V |
| 输出 | **按网桥适配器标签**：常见 **12V**；若标签是 9V/24V/48V 则按实际换 |
| 电流 | **≥1.5A**（网桥约 1A）。**买 2A/3A 标准款即可，更好**——电流额定是上限，负载按需取，不会灌坏；**别买 1A/0.5A**（贴太近会热/掉压） |
| 参考价 | ¥10–25 |
| 搜索词 | `48V转12V 2A 降压模块 宽压` |
| 坑 | 网桥若是 **PoE 供电**（网线供电），则不用这个模块，改用 PoE 注入器——**先看网桥原配适配器长什么样** |

### 1.4 保险丝座 + 保险丝 ×2（48V 两路进线各一）

| 项 | 要求 |
| --- | --- |
| 规格 | **48V 直流**、**2A**（总负载 ~0.8A，2A 留余量） |
| 类型 | 车用插片式（ATC/中号）或玻璃管式，**必须选"直流额定"**（交流保险丝在直流下断弧能力不足） |
| 参考价 | ¥5–15/套 |
| 搜索词 | `汽车保险丝座 中号 带线` `2A 保险丝 直流` |

### 1.5 防浪涌 / TVS 模块 ×2

| 项 | 要求 |
| --- | --- |
| 用途 | 抑制电机启停、48V 母线尖峰（电机是最大干扰源） |
| 规格 | 找卖家说：**"48V 直流车用、防电机尖峰"**，让他配（TVS 钳位电压要高于 54.6V、低于模块耐压） |
| 参考价 | ¥5–20/个 |
| 坑 | TVS 是**钳位**不是稳压，别拿它当降压用；接反会短路 |

### 1.6 抗干扰磁环 ×3

| 项 | 要求 |
| --- | --- |
| 类型 | **卡扣式**（免拆线，套上去扣住） |
| 数量 | USB-C 供电线、网线、48V 电源线 各一个 |
| 尺寸 | 按线径选（常见内径 5mm/7mm/9mm） |
| 参考价 | ¥1–3/个 |
| 位置 | 尽量**靠近 X5/网桥端**（抑制进入设备的噪声） |

### 1.7 12V 圆口公头线 ×1（模块 → 网桥）

| 项 | 要求 |
| --- | --- |
| 规格 | **先量网桥 DC 口内径**：常见 **5.5×2.1mm** 或 **5.5×2.5mm**（两种不能互插） |
| 极性 | **认准正负极**（一般"内正外负"），接反会烧网桥——**用万用表确认模块输出极性后再插** |
| 参考价 | ¥5–10 |
| 坑 | 别硬插！插不进就是尺寸不对，换对应规格，别用蛮力 |

### 1.8 线材、端子、热缩管、共地线（若干）

| 项 | 要求 |
| --- | --- |
| 48V/12V 电源线 | **20–22AWG** 足够（电流 ~1A）；选耐温硅胶线更好 |
| 共地线 | 一颗 M4/M5 接地端子 + 短粗线，把 X5、网桥、两模块、大板、电池负极 接到同一参考点 |
| 热缩管/端子 | 冷压端子 + 热缩管，**所有接头都要做绝缘** |
| 参考价 | ¥10–30 一包 |
| 坑 | **共地必须做**：不共地会出现通信乱码/网口丢包（我们串口、网口都依赖共地） |

### 1.9（可选）USB-C PD 电压/电流表 ×1

- 用途：想现场确认"X5 实际拿到多少 V/A"时，串在原装适配器↔X5 之间看一眼。
- 参考价：¥15–30。**非必需**（手册已明确 5V/5A，这只是加分验证）。

## 2. 拓扑选择：固定 5V 直降 vs PD 源模块

手册只要求"**支持 5V/5A 的电源适配器**"，没规定必须走 PD。两条路都合规，按你能买到的选：

| | 路 A：48→5V/6A 直降（**首选**） | 路 B：48V 输入 USB-C PD 源模块 |
| --- | --- | --- |
| 做法 | 降压模块输出 5V，经 5A 线接 X5 的 USB-C 接口 1 | 模块自带 USB-C 源逻辑（CC/PD），对 X5 广播 5V/5A |
| 优点 | 便宜、简单、模块遍地有 | 与 X5 原装适配器同机制，**USB-C 识别最可靠** |
| 风险 | **X5 可能因 CC 无标识而限流/不取电**（需实测，见 §5） | 模块较贵、48V 输入款少 |
| 买不到时 | — | 退路：48V→24V 降压 + 12–24V 输入的 PD 模块（多一小盒） |
| 参考价 | ¥15–40 + 线 ¥10–25 | ¥60–150 |

**建议**：先买路 A（便宜、到货快）。如果 §5 实测 X5 启动异常或满载重启，再加一个"USB-C CC 标识"小件（或改路 B）。

**绝对不要买**：固定 12V 输出的、或只到 5V/3A 的。

## 3. PC 端（笔记本侧）

- 田头给 **PC 端网桥**供电：一个 **12V 便携源**（12V PD 充电宝，或小块 12V 电池 + 对应圆口线）。
- 室内调试：直接用网桥**原装 AC 适配器**。
- 笔记本网口那根网线：**只传数据，不供电**（POE 不是我们方案）。

## 4. 接线图与顺序

```
48V 车电池正极 ──[2A保险丝]──┬──[TVS]──┬── 48→5V/6A 模块 ──5A USB-C线──→ X5(USB-C 接口1)
                            │  [磁环]  └── 48→12V/1.5A 模块 ──12V圆口线──→ 车端网桥 DC 口
48V 负极 ──────────────────┴── 全车共地参考点（X5/网桥/两模块/大板/电池负极 同点）

X5 网口 ──普通短网线──→ 车端网桥 LAN 口
```

**接线顺序（务必按此避免带电操作）**：
1. 断电，万用表测模块输出：48→5V 模块输出应在 5.0–5.1V；48→12V 输出 12V（±5%）。
2. 先接 48V 侧（经保险丝），**空载**上电复测输出电压。
3. 再接负载（X5 / 网桥），观察模块温度。
4. 最后插网线、上电验收。

**上电验收标志（手册）**：X5 **绿灯亮** = 供电正常；3.1.0 后 **橙灯闪烁** = 系统正常。

## 4.5 主电源拓扑与接地（实车事实，2026-09-12 用户提供）

**实车拓扑**：48V 电源正极 → 直流接触器；48V 负极 → 车架地。

| 点 | 结论 / 要求 |
| --- | --- |
| **直流接触器** | ① 触点按 **48V 直流额定**选（直流灭弧能力，不能拿普通交流接触器替代）；② **线圈并一只续流二极管**（防反峰打坏驱动）；③ 急停应使接触器**失电断开**（fail-safe：断电即断） |
| **X5/网桥取电点** | **建议独立"常电"支路**（接触器**之前** + 单独保险丝）：急停切动力后 X5/网桥仍在线，可读状态/日志。若从接触器**之后**取，急停会一并断电——更干净，但 X5 **瞬间掉电**（SD 卡损坏风险）且丢遥测。**需先确认接触器由谁控制（钥匙/急停/两者）再定** |
| **接地** | 负极接车架 ⇒ **车架即全车地**。X5、网桥、两模块、大板、电池负极**全部接到车架上的同一星形点**，不要各接各的 |
| **保险丝** | 负极已搭铁 ⇒ 正极碰壳即**直接短路**，48V 两路**必须各带保险丝**（2A） |
| **防地环** | 设备金属壳/安装孔直接搭铁会经车架形成**第二接地路径** → 用**绝缘柱**安装，或确保单点接地 |
| **网线** | 以太网变压器隔离，PC 侧（笔记本电池 + 便携源，浮地）**不会与车架成地环**，无需额外处理 |

## 5. 到货必做验收（10 分钟，接车前完成）

- [ ] 48→5V 模块**空载输出 = 5.0–5.1V**；48→12V = 12V
- [ ] 接 X5：**绿灯亮、橙灯闪**，SSH 能进（`ssh sunrise@192.168.127.10`）
- [ ] **满载测试**：X5 上跑一会儿负载（如 `sudo apt update` 或后续推理），确认**不重启/不欠压**（这是 5A 够不够的判据）
- [ ] 跑满载时模块**温升可接受**（手能碰）
- [ ] 网桥接 12V：能 ping 通、灯正常
- [ ] 网桥 DC 口极性正确（万用表确认内正外负）
- [ ] 全车共地已接
- [ ] 急停取电点实测为**常电**（不被急停切断）

| 轮次 | 错误说法 | 错因 |

| 初版 | "X5 仅 5V/5A、12V 会烧板，建议 48→5V/5A 直降、PD 不推荐" | 网络查不到官方页，却把推测当结论；且"绕开 PD"自相矛盾 |

| 三版 | "5V/5A 必须 PD 协商 + e-marker 线" | 超出手册原文，替手册加条件 |
| **定稿** | **USB-C 接口 1、5V/5A** | **手册原文**；实现方式手册未限定，固定 5V 直降与 PD 源皆可 |
