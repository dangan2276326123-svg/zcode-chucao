## 2. 一个数值上的疑点：四边不等长

按孔心读数算出的四边"工作铰距"：

| 边 | 铰距 mm | 依据 |
| --- | --- | --- |
| 电推杆 | 429.0 | 两端 φ10 铰孔 (−112,0,−21) ↔ (25,0,408) 的 XY 面投影 |
| 连杆1 | 385.0 | D25 ↔ D10（同一 X=−108 列，Z 差 385） |
| 连杆2 | 约 352 | D20 (0,110,20) ↔ D30 (0,20,360) |
| 连杆3 | 510.5 / 514.8 | D20 双孔 ↔ D10 双孔 |

平行四边形要求对边等长，这里 429/385/352/510 四条都不相等。两种可能，须作者指认：

1. 构型本身是**近似**平行四边形（农具提刀常见），那正文不能写"平行四边形机构"，要写"四连杆（近似平行四边形）"，并说明铲体姿态在行程内有轻微转动；
2. 我读到的孔**不是工作铰点**（例如把装配螺栓孔当成了铰孔），那需要给出每个连杆真正参与铰接的那一对孔。

这条不定，装配就是按错的几何拼的，所以它是本轮唯一的阻断项。

## 3. 对正文的两条影响（已改）

- **限深与提刀解耦的机构学理由**：仿形轮经刀柄2 支承在刀体上、与铲体同属一个随动体，轮—刀相对位置由结构固定 → 深度漂移只来自地表起伏与刀腿弹簧压缩量，不来自提刀高度。原 §2.3.2 写的"刀梁前部设置限深板/随地形浮动"没有把这层刚性关系说清。
- **传动比不是常数**：四连杆瞬时传动比沿行程变化 → M9/M10 必须在行程两端各量一次并补中间点，不能用单点比值去换算"满行程约 20 s"。
