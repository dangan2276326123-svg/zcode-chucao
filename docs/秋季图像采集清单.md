# 秋季田间图像采集清单（C1 任务执行文档）

> 目标：为秋季模型微调采集 200-300 张标注级图像 + 3 段验证视频。
> 依据：avi 帧域差异实测（夏季权重在当前田况过分割，fg≈0.55，双墙不可用）。
> **时限：2026-10-15 前**（之后杂草枯黄，域又变了）。
> 采集完成后图像放 `D:\ai work\zcode\autumn_data\raw\<类别>\`，命名见文末。

## 1. 设备与机位

- **优先用车上真机位拍**：相机装到 0.9 m 前视低机位（最终作业位置），俯角约 20°——采集域=部署域，比什么都重要。
- 没条件上车时用手机 substitute：手持模拟同机位（离地 ~0.9m、前倾 ~20°、镜头高度对准行间延伸方向），标注时注明。
- 分辨率 ≥1920×1080（与标定/训练域一致）；格式 JPG；视频 1080p25。

## 2. 拍摄矩阵（每格代表一个拍摄批次）

四个维度全覆盖，**每格 ≥15 张**，合计 240 张左右：

| 维度 | 取值 |
| --- | --- |
| 光照 | ① 晴天顺光 ② 晴天逆光 ③ 阴天（3 选 3 都要） |
| 时段 | 上午（侧影长）/ 正午 / 下午（逆光多） |
| 行况 | ① 行间干净（草少）② 行间中度杂草（主要工况）③ 行间茂密（接近封垄） |
| 视角 | ① 正对行间 ② 左偏 ~15° ③ 右偏 ~15°（模拟车体横向纠偏时的视野） |

优先级（时间不够先保这些）：
1. **晴天+中度杂草+正对**（主工况，≥60 张）
2. 晴天逆光+中度（逆光是分割翻车重灾区，≥30 张）
3. 阴天+中度（≥30 张）
4. 干净/茂密行况各 ≥15 张
5. 左右偏角随拍随带，不单独跑一趟

## 3. 内容要求（标注级）

- 画面内**必须含两条完整的芍药行墙**（左右边界都在画面里）——双墙中心线是监督信号。
- 帧与帧之间**位移 ≥0.5m**（避免大量近重复帧）。
- 芍药各生长阶段都拍：秋季叶片完整期/半枯期/枯萎期（若有）。
- 拍几张**干扰特写**（各 5 张即可）：滴灌带（蓝/黑管）、地膜残留、大块阴影、人脚/鞋入镜——这些是误检源，标注时重点照顾。

## 4. 视频验证集（3 段，不用标注）

- 沿行间匀速走拍 3 段：晴天逆光 1 段、阴天 1 段、任意 1 段；每段 ≥30s、1080p25、走直线。
- 用途：微调后的留出验证（回放测 status=dual 比例），**不进训练集**。
- 命名：`autumn_video1_sun_backlight.avi` 等。

## 5. 标注规范（回来后我出工具，你只管拍）

- 工具：labelme 多边形，两类：`peony`（芍药植株，含茎叶）/ `background`（其余一切，含杂草——行间除草只认行墙，杂草归背景）。
- 边界精度：叶片边缘贴 合到 ±3 px 即可，不抠细节。
- 遮挡/截断：出画植株按可见部分标，不预测。
- 标注量：从 240 张里标 **150 张**（矩阵每格按比例抽），我抽检 20 张质检。

## 6. 命名与回传

```
autumn_data/raw/sun_front_dense/IMG_0001.jpg   # {光照}_{视角}_{行况}/序号
autumn_data/raw/overcast_mid_offsetL/IMG_0037.jpg
```
类别关键词：光照 `sun_front / sun_back / overcast`；行况 `clean / mid / dense`；视角 `front / offsetL / offsetR`。
