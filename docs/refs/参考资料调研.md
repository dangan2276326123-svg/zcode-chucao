## 一、王硕论文（PDF 已解析）

**文件**：`C:\Users\22763\OneDrive\Desktop\论文\王硕080202机械电子工程20240605204550.pdf`（166 页）
**注意**：文件名虽为"机械电子工程"（硕士学科代码 080202），但正文页眉显示为**中国农业大学博士学位论文**，主题为"基于视觉导航的生菜田株间除草机器人"（生菜株间除草，非行间，但技术栈与本项目高度同源）。共 6 章，含完整目录书签。

### 1.1 论文主题与整体方案

- **总体方案**：四轮独立驱动独立转向（4WIS4WD）移动平台 + 凸轮摆杆式株间除草装置（后挂）+ 前置相机视觉导航。YOLOv5s（PP-LCNet 轻量化 + CBAM）识别生菜苗用于避苗；DeepLabv3+（改进）做垄语义分割，与 EXG/EXCg 植被指数特征融合后生成特征点，经距离滤波 + 改进 PROSAC 拟合导航线；控制端用 Kalman 滤波平滑导航参数，构建运动误差模型，设计带约束 MPC 并用模糊推理自适应调整权重矩阵；CoppeliaSim 仿真 + 田间试验验证。
- **关键结果**（摘要，p3–4）：
  - 改进 YOLOv5s 检测速度提升 91.12%，mAP 98.79%；
  - 导航线与人工标注真值平均重合度 0.93，拟合精度比霍夫变换 / 纯语义分割（SEM-MID）高 51.5% / 22.1%，25.5 FPS；
  - 田间导航横向偏差绝对平均值与 RMSE 均在 3 cm 以内；综合除草试验除草率 92.07%、伤苗率 2.51%。

### 1.2 对本项目可借鉴的方法、试验设计、指标定义

1. **视觉导航线提取链路**（第三章，p64–99，与本项目"DeepLabV3+ + IPM + 中心线"几乎同构）：
   - 其"垄语义分割 + EXCg 颜色特征融合 → 逐行检测苗带线 → 中心特征点 → 拟合导航线"的思路，可直接对应本项目的"双墙（两条作物行带）中心线"：它对**每一行单独检测苗带线再合成导航线**（p93），因此单行作物缺失时仍稳定——这正是双墙中心线法的核心论据，可在方法章节直接引用对比。
   - **距离滤波 + 改进 PROSAC 剔除离群中心点**（3.6 节，p83–89）：对处理垄边杂草产生的离群特征点非常实用，可作为本项目中心线拟合前的去噪手段或对比基线。
   - **杂草密度定量定义**（式 3-25，p94）：以逐行像素占比定义沟内杂草密度 ρF 和垄上杂草密度 ρR（0~1），本项目可照搬该定义做"不同杂草密度下中心线提取鲁棒性"试验。
   - **相机高度影响试验**（3.7.4，p95–96）：0.82/1.2/1.5 m 三档相机高度对导航线提取的影响，可作为本项目相机安装高度选型论证的参照试验设计。
2. **导航线拟合精度指标 CRDA**（3.7.1，p90，式 3-24）：作物行检测精度（Crop Row Detection Accuracy），逐行比较提取线与人工标注真值的横坐标偏差，归一化到 [0,1]。本项目"分割/中心线精度"试验可直接采用该指标（含其 IPM 调整系数），并配套 CRDA_avg、CRDA_std、FPS 三列表（表 3-5，p93）。
3. **导航控制性能指标体系**（5.2.1，p136–137）：以 RTK-GPS 10 Hz 记录位姿，每隔 5 m 采真值点最小二乘拟合导航线真值；定义横向/航向偏差的 **Max of AE、Mean of AE、RMSE、SD 四指标**（式 5-1）。本项目用 PID 而非 MPC，但指标体系、真值标定流程（垄中心重合行驶采点）可整体迁移；若无 RTK，可用高分辨率 RTK 或人工放样标杆替代并说明。
4. **除草作业指标定义**（5.3.1，p142–143，式 5-2）：除草率 RC=(1−NL/NC)×100%（明确"根部完全断裂/整体掩埋/根全部掀出"算成功）、伤苗率 RD=ND/NE×100%（"碰伤叶片即算伤苗"）、功耗 RW=ΣUI/t（30 Hz 采样电压电流）。另用**响应面分析法**优化凸轮转速、入土深度、前进速度三因素（5.3.1，p142–147）——本项目中间刀作业参数优化试验可套用同样框架。
5. **单因素场景化田间试验矩阵**（5.2.2–5.2.4，p137–141）：不同杂草密度、不同负载、不同前进速度、不同光照（晴天/阴天/暗光）、不同作物生长期分别做导航试验，每垄重复 3 次、出发区 2 m + 记录区 52 m + 停车区 2 m 的方案，可直接作为本项目试验章节的方案模板。
6. **绪论综述骨架**（1.2，p19–30）：除草机器人技术 → 视觉导航线提取 → 轨迹跟踪控制三段式综述，参考文献编号体系可作为本项目绪论文献池索引。

## 二、李俊论文（PDF 已解析）

**文件**：`C:\Users\22763\OneDrive\Desktop\论文\玉米作物行间除草机器人行走控制方法与系统设计_李俊.pdf`（79 页，安徽农业大学硕士论文，用户已将原 CAJ 转为 PDF）
**主题**：玉米生长中期**行间**除草机器人——履带底盘 + 机器视觉导航线提取 + STM32 行走控制 + 末端旋转刀除草。这是与本项目"行间除草"定位最直接的国内先例，但技术路线为传统视觉，恰好构成本项目方法升级的对照。

### 2.1 论文主题与整体方案

- **整机**（第二章，p22–29）：履带式底盘（双电机**差速转向**，整机 1400×380×700 mm、80 kg、48 V 供电、作业速度 0.5–1.5 m/s），设计依据明确针对玉米行距 55–60 cm 限宽、限重（防土壤板结）、低重心；除草系统为电动伸缩杆升降 + 轮毂电机带动刀片。
- **视觉导航**（第三章，p30–52）：单目相机采玉米行间图像 → RGB 颜色分析 + 加权灰度化 + OTSU 最大类间方差二值化 → **CAANY 边缘检测**完成"玉米作物与蓝天背景"分割 → **RANSAC + 最小二乘**拟合导航线 → 经相机标定（Matlab Camera Calibration，25 张棋盘格图）由成像模型解算机器人**偏航角**作为唯一位姿输出。注意：其分割对象是"作物 vs 蓝天"（俯仰视角下作物高过相机、背景为天空），并非土壤背景下的作物/杂草分割，也未用 IPM。
- **行走控制**（第四章，p53–60）：STM32F1-V3 底层控制板（PWM 控 ZM-6615 无刷电机驱动器、降压电路、SBUS 遥控接收）+ Keil 下位机程序 + VC++/MFC 上位机导航软件（实时显示原图/OTSU 分割图/边缘图/导航线/偏航角与左偏-右偏-正常状态）。控制策略仅为**偏航角符号判断的开关式转向**（左偏右转、右偏左转），未见 PID/横向偏差闭环。
- **田间试验**（第五章，p61–71）：安徽农业大学玉米示范田（玉米株高约 70 cm、行间杂草高约 30 cm）。用 **MTi-G-710 GNSS/INS**（置于近重心处，四元数解算姿态）测行走稳定性，指标为**最大横摆角**与**行间除草率** η₁=(1−Q_H/Q_Z)×100%（式见 p64）。单因素试验（刀片转速 100–500 rpm、入土深度 10–30 mm、入土角度 30–75°）确定有效区间：转速 300–500 rpm、深度 20–30 mm、角度 30–60°（p64–66）；再用 Design-Expert 8.0 做**正交旋转组合试验**，拟合二次回归模型与 3D 响应曲面（p67–70），最优组合：刀片转速 409.95 rpm、入土深度 25.38 mm、入土角度 42.63°，除草率 84.52%、最大横摆角 1.9°（p71）。

### 2.2 可借鉴的方法与试验设计（含页码）

1. **"设计依据→技术参数表"写作范式**（2.1.1–2.1.2，p22–23）：从行距（55–60 cm）反推整机限宽、从防板结推限重、从稳定性推低重心，最后落到主要技术参数表。本项目芍药行间版可直接套用：由芍药行距/株高/垄形反推底盘尺寸与刀臂跨度。
2. **单相机标定 + 位姿解算推导链**（3.5.1–3.5.2，p47–51）：世界系→相机系→图像系→像素系的四级变换与畸变模型（式 3-24~3-29）、Matlab 标定操作步骤（25 张图、剔除大误差图、导出内外参）。本项目 IPM 一章可用更完整的现代表述引用此推导框架，并指出李俊仅输出偏航角、未解算横向偏差——本项目以 IPM + 双墙中心线同时输出**横向偏差与航向偏差**是明确改进。
3. **导航线拟合对照基线**（3.4，p44–46）：RANSAC + 最小二乘的传统拟合，可与王硕的 PROSAC、本项目的双墙中心线拟合同台对比，作为"传统方法在杂草密集/缺失场景下精度不足"的论据。
4. **开关式控制→PID 的对照论证**（4.3.2，p58）：其仅按偏航角符号做恒定转向修正、无偏差幅值与积分项，易在窄行间产生超调振荡；这为本项目"中间刀 + PID 连续控制"的必要性提供直接对照（可引用其流程图与控制逻辑作为现有不足）。
5. **试验指标与仪器方案**（5.2.3–5.2.4、5.3，p63–65）：GNSS/INS（MTi-G-710）测最大横摆角评价行走稳定性——本项目若不配 RTK，可仅用 IMU 横摆角 + 摄像机/标尺测横向偏差的组合；行间除草率公式 η₁=(1−除草后杂草数/除草前杂草数)×100% 可直接采用（本项目再补充伤苗率）。
6. **"单因素初选 + 正交旋转组合回归"两段式优化试验**（5.3–5.4，p64–71）：Design-Expert 因素水平编码表、二次多项式回归、交互效应 3D 响应曲面、Optimization 求最优组合的完整流程，是本项目中间刀作业参数（刀转速/入土深度/前进速度）优化试验的现成模板；评价指标同时含"除草率↑ + 最大横摆角↓"双目标，兼顾除草效果与行走稳定，值得本项目沿用。

### 2.3 与本项目"芍药行间"的差异点（论文"本研究必要性"论据）

| 维度 | 李俊（玉米行间） | 本项目（芍药行间） | 引申论据 |
|---|---|---|---|
| 作物与行距 | 玉米，行距 55–60 cm，株高约 70 cm（生长中期） | 芍药为多年生宿根作物，行距与冠幅、株高与玉米差异大，且生长早期冠层覆盖度低 | 行距/冠层结构不同 → 其限宽尺寸与"作物对蓝天"的俯仰成像假设不可直接迁移，需重新设计感知几何 |
| 感知背景 | 分割对象为"作物 vs **蓝天**"（利用高株作物与天空对比） | 芍药植株矮、相机视线背景主要是**土壤与杂草** | 蓝天对比法失效 → 必须采用 DeepLabV3+ 语义分割在土壤/杂草背景下区分作物带 |
| 导航线方法 | OTSU + CAANY 边缘 + RANSAC 单线拟合，仅输出偏航角 | DeepLabV3+ 分割 + IPM + 双墙中心线，同时输出横向偏差与航向偏差 | 传统方法在杂草密集、光照变化下鲁棒性不足（其 6.2 展望（1）p73 自认仅在理想天气光照下验证） |
| 底盘形态 | 履带式、80 kg、双电机差速 + SBUS **遥控为主** | 轮式差速底盘，自主导航 | 其展望（2）（p73）自述"尚未进行沿导航线的自主行走试验"——自主行间导航闭环正是本项目补齐的空白 |
| 控制方法 | 偏航角符号开关式转向 | PID 连续闭环（横向+航向双反馈） | 开关控制在窄行间易振荡，PID 引入幅值信息提高稳线精度 |
| 试验指标 | 除草率 + 最大横摆角（无伤苗率、无导航偏差统计） | 除草率 + 伤苗率 + 横向/航向偏差四指标 | 现有行间除草评价体系不完整，本项目建立更全面指标体系 |

### 2.4 可引用到本项目论文的具体点（按章）

## 三、GitHub 开源项目调研

### 3.1 geezacoleman/OpenWeedLocator（OWL）

- 悉尼大学团队的开源低成本除草喷洒装置，核心是"相机 + 树莓派 4 实时检测 + GPIO 继电器喷阀"的感知-执行闭环；早期为绿棕（green-on-brown）HSV 颜色检测，后扩展到基于 YOLO 的绿绿（green-on-green）识别。配套论文 Coleman et al., 2021（Computers and Electronics in Agriculture, 188, 106332）与 2022 Zenodo 设备论文。
- **田间标定流程**值得抄：手册明确要求手动固定相机曝光（防止自动曝光改变绿色判别阈值）、逐场景调节检测阈值与 ROI（最大/最小目标宽高、喷阀坐标窗口），并强调 GOG 模型必须用**同作物同生长期同田块**数据训练、用混淆矩阵逐类核查弱点。
- 对本项目借鉴：① 相机**手动曝光锁定**应写入本项目标定规程，否则分割模型在光照变化下漂移；② "ROI 窗口 + 阈值"的执行端安全约束思路可用于中间刀触发区域判定；③ 其 wiki 的"检测参数调优→混淆矩阵核查→田间复测"闭环可作为本项目试验 SOP 参考。文档结构（README + wiki 分层：硬件装配/软件/标定/故障排查）也值得本项目代码仓模仿。

### 3.2 PRBonn/cropandweed-dataset（CropAndWeed / CW）

- 波恩大学 Stachniss 组的多域作物-杂草数据集：先期 75 张大图（3456×5184）带像素级**茎、叶、作物/杂草**标注；后续扩展约 7000 张，覆盖 12 种作物/杂草、10 个语义类、多种土壤背景与生长期，标注以 24 倍降采样 PNG/JSON/COCO 提供，附上采样与匿名化工具。
- **许可**：数据仅限**非商业研究用途**（继承 EPFL CVLAB LaMFor 数据集许可），代码 MIT。写论文引用其论文（arXiv:2312.10548 等）。
- 对本项目借鉴：① 作为 DeepLabV3+ 的**预训练/预标注数据源**，再用小规模芍药田自采数据微调，缓解标注量不足；② 其"crop/weed/soil + stem/leaf"分层标注体系可作为本项目标注类别设计的模板（茎部标注对除草执行端定位有额外价值）；③ 多域（土壤/生长期/相机）采集策略可直接指导本项目数据集的多样性设计；④ 注意非商用约束不影响硕士论文使用，但若涉产业化需替换数据。

### 3.3 Zauberzeug/field_friend（feldfreund_devkit）与 Nindamani

- **Zauberzeug/field_friend**：商用除草机器人 Feldschärpe/Field Friend 的核心代码（feldfreund_devkit 为其 fork），Python/PyTorch on Jetson + ESP32 电机控制，基于自研 zeugma 框架的类 ROS 数据流。亮点是**监控与安全分层**：NiceGUI 主窗口聚合实时相机画面+检测框、状态图表、交互式地图与遥操作，感知模块与执行模块解耦、状态可观测。
- **Nindamani**（IROS 2020，Natarajan & Jeyaseelan）：AI 机械式除草机器人，YOLOv2-Tiny 检测 + "weed/non-weed"状态估计决策 + 四个独立旋转铲除草臂随车同步动作，高粱田实测。
- 对本项目借鉴：① field_friend 的**感知-执行解耦 + 状态监控面板**模式：本项目可将"分割结果/中心线偏差/刀盘状态/电池电压"做成上位机可视化，调试与田间排障效率大增；② 其 ESP32 下位机 + 上位机决策的分架构，对应本项目"工控机感知决策 + 底盘/刀盘 MCU 执行"的分层，可引用其接口划分思路；③ Nindamani 的"检测 → 状态估计（是否为目标）→ 机械执行同步"闭环提示：本项目中间刀启停应叠加作物/杂草判定门控（即使行间作业，也应防误伤偶入行的芍药植株），这一安全逻辑可在方法章单列一小节。
