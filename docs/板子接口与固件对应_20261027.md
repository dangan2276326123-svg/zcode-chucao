# 板子接口 ↔ 固件引脚对应（2026-10-27，逐条从代码读出）

**为什么有这份表**：作者 2026-10-27 指出 **T4/T5 接的是行走电机与转向电机控制器**，
而我们此前的现场注记写的是"T4=In 输入（限位？）、T5=Out 输出（刀继电器）"（见
`04_figures/figures_manifest.md` 图2-7 那一行）。两者不能同时成立，所以这次不猜——
把**固件到底用了哪些引脚**逐条读出来，接口号与引脚的关系留给原理图/跟线去钉。

**三条口径**

1. 本表只回答"固件用了哪些引脚与外设"。**板上 T 号丝印 → MCU 引脚，需要原理图**，本仓没有；
   目前只有 T3（SBUS，作者 09-05 注记 + 代码吻合）与 T4/T5（作者 10-27 口述）有外部信息。
2. **"在用"的定义 = 进了 Keil 工程（`USER/PWM.uvprojx`）且被 `main()` 调用链初始化。**
   `HARDWARE/` 目录里躺着但没进工程、或进了工程却没被调用的，一律记"未用"——
   因为"文件存在"最容易被误当成"功能在用"，本仓在这上面栽过不止一次。
3. 引脚读自 `GPIO_Init` / `GPIO_PinAFConfig` 的实际参数；**注释里的引脚号只作旁证**——
   本仓注释有复制粘贴的旧值（`SYSTEM/usart/usart.c` 注释写"USART1 / PA9 / PA10"，
   代码配的是 **USART6 / PG9 / PG14**）。

## 二、在树上但**没在用**（别当成"板上接了这些"）

- **`HARDWARE/DRIVER/driver.c`、`HARDWARE/bujin_motor/bujin_motor.c`、`HARDWARE/bujin_motor/motor.c`
  根本没进 Keil 工程**（`PWM.uvprojx` 只列 41 个文件，这三个不在其中）⇒ 它们里的
  PA15/TIM2、PB4/TIM3、PB6/TIM4、PA0/TIM5，以及 `motor.c` 那一大串
  USART1/USART2/USART3 与 GPIO，**一行都不参与编译**。
- **`HARDWARE/ADC/adc.c` 在工程里，但 STM32 片内 ADC 没被调用**：
  `ADC_angle_Check()` / `ADC_electric_Check()` 的真实实现在 `iic/iic.c:606/631`，
  走的是 ADS1115 + 软件 I²C。⇒ 片内 ADC 这一路空着。
- `sensor.c`、`work_control.c`、`can.c`、`key.c`、`lcd.c`、`beep.c`、`uart3.c`：
  在工程里，但 `main()` 里没有它们的初始化调用，也没找到调用点 ⇒ 未启用。
  （显示屏走的是 UART5 那条"上位机（显示屏）"，不是 LCD 的 FSMC 并口。）
- 因此 **KEY 的 PE2/3/4 与 PA0、BEEP 的 PF8、LCD 的 FSMC 那一大片引脚，都不代表板上接了东西。**

## 三、一处冲突候选（要实测，不当结论）

**USART6 的引脚被两处各配一遍。** `uart_init()`（`main.c:151`，115200）把 USART6 配到
**PG9/PG14** 并 `USART_Init(USART6)`；随后 `retrofit_init()`（`main.c:163`）又把
**PC6/PC7** 配成 USART6、再 `USART_Init(USART6)` 一次。两套引脚同时处于 AF 状态，
接收脚到底听哪一只没有文档保证（发送侧 PG14 与 PC7 会同时输出同一路 TX）。
⇒ 这是台账 **Fw-16"反向下行链路不通"的一个候选机制**：把 `uart_init()` 里 USART6 的
引脚配置去掉（或改到别的不用的串口）再试一次，10 分钟即可判真假。**未实测前不当结论。**

**另一处已排除，写在这里免得有人再查**：PF9 在 `led.c` 里既是 `LED_Init()` 的目标、
又是 1 号轮方向（`replay_switch` ch1）。逐行核对后：运行期只有 `replay_switch` 写它
（`led.c:412`），LED 那几行只是初始化时清零 ⇒ **不是冲突**。

## 四、要把"T 号"钉死还缺什么

- **板子原理图，或一次跟线**。按本表的引脚分布，"T4/T5 是电机线束"更说得通：
  行走电机要 4 路 PWM + 4 路方向共 8 条线，转向要 UART4 两条，这两束线正好是两个大端子；
  而"刀继电器"在固件里只有 PD4/5/6 三根、且经 74HC245，形态上更像 3～4 针的小接口。
- **在作者确认 T4/T5 之前，论文与图注一律不改**——现在两边口径冲突（照片注记 vs 口述），
  按 AGENTS 的事实权威序，作者口述高于我们当年的注记，但改之前要先分清是"注记标错了端子号"
  还是"当年看的是另一块板/另一束线"。**待确认项**：
  ① T4 与 T5 哪个是行走、哪个是转向；
  ② 刀继电器那三路到底从板上哪个端子出去（若根本不从主控板出去——Hw-31 已知那块外接
  继电器板现在独立——则图 2-7 里"T5=刀继电器输出"整句作废，但"板上这个口存在"仍是事实）。
