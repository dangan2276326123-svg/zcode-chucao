# 大车固件除草改造集成说明（firmware/）

**状态（2026-09-02）：已在 Keil UV4 + ARMCC 5.06 编译通过（0 错误），完整集成版位于 `firmware/大车proj/大车/`，hex 已生成（OBJ/ 下）。以下集成步骤已在工作区副本中完成**，用户侧只剩烧录与台架标定。原 zip 里的旧 OBJ 会导致假链接错误（旧 usart.o 自带 USART6 中断），务必全量重编。

## 文件
- `protocol.c/h` — 0xA5 0x5A 帧解析/构建 + CRC16，与 `common/protocol.py` 逐字节一致
- `retrofit.c/h` — 全部新增功能（UART6 链路、双指令源、刀控联锁、看门狗、步进、轮速捕获、状态帧）

## 集成步骤（Keil）
1. 把 `protocol.c/h`、`retrofit.c/h` 加入工程（HARDWARE 组即可），Include Path 加 `firmware/`。
2. `main.c`：在外设初始化区（`delay_init(168)` 之后）加 `retrofit_init();`；主循环里接一个 1 ms 时基——最简单是用 `delay.c` 里现成的 SysTick：在 `delay_ms` 之外找个已运行的 1 ms 中断（或新建 TIM6 中断，148 行处已有 TIM6 空闲），在中断里调 `retrofit_poll_1ms();`。
3. **SBUS 心跳对接**：`telecontrol.c` 的 SBUS 接收成功处（`CHANGE_FLAG=1` 附近）加一句 `extern volatile uint32_t sbus_last_ms; sbus_last_ms = <当前 ms>;`（retrofit.c 顶部 extern 即可）。
4. **底盘指令注入（双指令源核心）**：`car_control.c` 的 `Out_Pwm()` 开头加：
   ```c
   extern uint8_t retrofit_mode(void);
   extern void retrofit_get_wheel_cmd(float *vl, float *vr);
   float vl, vr;
   if (retrofit_mode() == 1 /*AUTO*/) {
       retrofit_get_wheel_cmd(&vl, &vr);
       veloc[0]=veloc[2]=vl; veloc[1]=veloc[3]=vr;  /* 左前/左后=vl, 右前/右后=vr */
       return;  /* 跳过 SBUS 通道映射 */
   }
   /* MANUAL：原逻辑不动 */
   ```
   （`retrofit_get_wheel_cmd` 需在 retrofit.c 补一个两行实现，返回 `cmd_vl/cmd_vr`——留给你编译时加，或在移植时告诉我报错信息。）
5. **急停硬件线**：保留原 PA5 大继电器作为最后一级；ESTOP 状态下 retrofit 已强制提刀（PD4/5/6 全高），确认实车继电器常闭/常开与代码假设一致（13.3 待确认项①②）。
6. 编译目标零警告后，先用 USB-TTL 跑 `python common/uart_vectors.py --dump` 的 8 组向量对拍，再接树莓派。

## 台架验收（对应 v0.7 §3）
- 8 组向量：6 组有效帧正确执行，2 组坏帧被丢弃
- AUTO 中拔串口线 → 500 ms 内急停+提刀
- ESTOP 后软件发任何帧不能解除，必须 `retrofit_clear_estop()`（接按键）
- 步进：±20 mm 阶跃，百分表重复定位 ≤0.5 mm
- 轮速：手转轮子，PC 收到 0x10 帧速度值连续合理

## 本机已做的集成改动（均已编译验证）
1. `USER/main.c`：`retrofit_init()` 挂在 `TIM1_PWM_Init` 之后
